### 🚀 GitHub 热门项目

今日 Trending 主题：**AI Agent 工具链** 与 **反追踪无头浏览器** 双线并进，微软、OpenAI、字节、HeyGen 大厂项目同屏竞争：

- **microsoft/markitdown**（Python）— 微软出品：把各类办公文档/文件批量转 Markdown 的命令行工具，喂给 LLM 前处理利器，常年热榜常客。
- **openai/skills**（Python）— OpenAI 官方 Codex Skills 技能目录，Agent 技能生态的官方"货架"。
- **bytedance/deer-flow**（Python）— 字节开源的长周期 SuperAgent 框架：自主研究、写代码、产出内容，主打"跑得久、办得成事"。
- **heygen-com/hyperframes**（TypeScript）— 写 HTML 直接渲染成视频，面向 Agent 的"网页即分镜"方案。
- **jo-inc/camofox-browser**（JavaScript）— 隐身无头浏览器：专为 AI Agent 绕过 Cloudflare 等反爬/机器人检测设计。
- **lightpanda-io/browser**（Zig）— Lightpanda：为 AI 和自动化设计的极轻量无头浏览器，Zig 写的性能取向新秀。
- **The-Swarm-Corporation/AutoHedge**（Python）— 几分钟搭一个"自动驾驶"对冲基金，量化玩家可围观其回测与组合逻辑。
- **BraveOPotato/FckSignups**（TypeScript）— 收录**免注册、纯网页可用**的开源工具清单，白嫖党收藏夹。
- **MoonTechLab/LunaTV**（TypeScript）— 开源 TV 直播聚合类项目（CC BY-NC-SA 协议，禁止商用）。
