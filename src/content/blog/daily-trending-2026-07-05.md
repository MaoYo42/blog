### 🚀 GitHub 热门项目

本周 GitHub 趋势上涌现了一批高质量新项目：

1. **[Strix](https://github.com/usestrix/strix)** — 开源 AI 渗透测试工具，自动发现并修复应用漏洞。安全团队的新玩具。
2. **[Alibaba Page Agent](https://github.com/alibaba/page-agent)** — 阿里巴巴出品的 JavaScript 页面内 GUI Agent，用自然语言控制网页界面。
3. **[xbtlin/ai-berkshire](https://github.com/xbtlin/ai-berkshire)** — 基于 Claude Code / Codex 的价值投资研究框架，融合巴菲特·芒格·段永平·李录四大师方法论。
4. **[browser-use/video-use](https://github.com/browser-use/video-use)** — 用编码 Agent 编辑视频，自动化视频处理管线。
5. **[exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)** — 包含 433 种健身动作的全面数据集，含名称、类别、目标肌群等信息。
