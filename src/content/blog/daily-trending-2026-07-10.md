## 🚀 GitHub 热门项目

### 1. [MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search)
基于 Claude Code 的 AI 驱动求职框架。填写个人资料后，AI 自动评估职位匹配度、定制简历、撰写求职信，实现求职流程全自动化。

### 2. [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)
生产级 AI 编码 Agent 技能集合，提升编码 Agent 在处理实际项目时的工程能力。来自 Google Chrome 团队专家。

### 3. [iOfficeAI/OfficeCLI](https://github.com/iOfficeAI/OfficeCLI)
首个专为 AI Agent 打造的 Office 套件命令行工具，支持读写编辑 Word、Excel、PowerPoint 文件。开源免费。

### 4. [voltagent/awesome-design-md](https://github.com/voltagent/awesome-design-md)
汇集全球品牌设计系统的 `DESIGN.md` 文件合集。投入项目即可让 AI 编码 Agent 生成匹配的品牌风格 UI。

### 5. [anthropics/claude-cookbooks](https://github.com/anthropics/claude-cookbooks)
Anthropic 官方发布的 Claude Cookbooks 合集，包含各种有趣实用的 Notebook 示例，展示 Claude 的创意使用方式。

### 6. [vxcontrol/pentagi](https://github.com/vxcontrol/pentagi)
完全自主的 AI Agent 系统，可独立执行复杂的渗透测试任务，覆盖全链路安全评估。

### 7. [wonderwhy-er/DesktopCommanderMCP](https://github.com/wonderwhy-er/DesktopCommanderMCP)
为 Claude 打造的 MCP 服务器，提供终端控制、文件搜索和差异编辑能力，增强 Claude 的桌面端交互。

### 8. [imthenachoman/How-To-Secure-A-Linux-Server](https://github.com/imthenachoman/How-To-Secure-A-Linux-Server)
知名 Linux 服务器安全加固指南，覆盖从基础到进阶的安全配置最佳实践。
