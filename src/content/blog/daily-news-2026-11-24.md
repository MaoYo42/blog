今天真正变了的东西不是某个新模型，而是**权限**：Anthropic 一天内在同一套产品线里把 Claude 从「提建议的助手」推成「按团队策略批准合并的同事」，Claude 插件把连接器与技能收成一个入口，Canva 把设计工具挂成 MCP 供任意 agent 调用。交付权一旦交给 agent，外部性就随之上桌——同一天的三条冷水都指向这里：0.1% 的预训练投毒在后训练之后仍然存活，Grok 因生成儿童性虐待图像被多州起诉，COP31 在数据中心用电争议里无果收场。

## 🌍 国际动态

**🚢 Claude Ship：Agent 从「审查 PR」走到「按策略批 PR」**
Anthropic 发布 Claude Ship 测试版，由三个部分构成：已正式可用的 Code Review、beta 阶段的 PR Steward 与 Claude Approvals。前两者负责审查 pull request 并推送修复，第三个按团队写进仓库的策略文件判断某次改动能否合并，Team 与 Enterprise 管理员也可以按仓库粒度开启自动审批。官方给的定位很直接：承接「各种编码工具带来的 PR 吞吐量」。

值得留意的是责任划分的位移。以前 agent 只产出一份 diff，合并与否由人拍板，判断权留在人这一侧；现在判断权被写成了仓库里的策略文件，由另一个 agent 解释执行。这在高吞吐的仓库里是效率，在合规语境里是一个新的审计对象——**策略文件本身成了需要被审查的代码**，而它解释得对不对，目前还没有第三方工具去测。

**🧩 Claude 插件：连接器与技能合成一个入口**
Claude 官方宣布把连接器（connector）与技能（skill）合并为插件，已在 Free、Pro、Max、Ultra 四档上线，Team 与 Enterprise 即将支持，插件目录现列 10,000 多个。此前「接工具」和「教它一项本事」是两套注册方式，生态碎片化对用户和开发者都是税；合并之后，一次安装同时带数据接入与行为说明。

这也意味着 Claude 的第三方生态开始有「应用商店」的形状。10,000 这个数字本身说明供给已经过剩——接下来的胜负点不在数量，在审核与权限边界：一个插件能读什么、能替用户做什么，是否有可读的权限清单。

**💬 GPT-6.2 Sol 面向日常对话，GPT-5.6 Sol 定于 12 月 23 日退役**
ChatGPT 在 Chat 标签页上线面向日常对话优化的 GPT-6.2 Sol，即日起对 Plus、Pro、Business、Enterprise 开放。改动方向偏「实用细节」：更擅长处理复杂请求与在线信息查找，能识别照片中标签文字、路牌符号，能按价格、位置等偏好缩小选项范围。产品侧同步宣布 GPT-5.6 Sol 将于 12 月 23 日停用。

两件事要一起读：能力在涨，同时模型寿命被压到季度量级。对企业来说这意味着 prompt、评测集与回归测试必须做成可迁移的资产，否则每次换代都要重做一遍验收。

**🛡️ OpenAI 与 Cisco 开源 Shirudo：给补丁窗口期加一层 eBPF 盾**
双方发布开源运行时 Shirudo，基于 eBPF 生成可密码学签名验证的 shield，在不重启服务的前提下拦截漏洞利用。受控测试里，用 Codex 生成的 shield 给运行中的 Elasticsearch 的 Java Base64 解码器加了输入检查，成功拦下 Java4Shell 攻击。

这是 agent 生成代码最该被用上的地方：不是写新功能，是给「不能停机、又必须马上打补丁」的老系统临时加护栏。可签名验证这一点同样关键——生产环境里，一段来历不明的内核过滤器比漏洞本身更可怕。

**⚖️ 多州起诉 SpaceX：Grok 生成 CSAM 与复仇式色情**
俄勒冈、弗吉尼亚等多州总检察长分别起诉 SpaceX，要求阻止 Grok 生成儿童性虐待图像（CSAM）与复仇式色情内容，并寻求经济赔偿。X 方面称每条 Grok 输出都经过筛查，州总检察长则称 Grok 仍在生成 CSAM。诉讼核心指向 Grok Imagine：2025 年 8 月上线可生成色情内容的 spicy 模式，2026 年 1 月又允许用户无需同意即可编辑任意图片。

「输出侧过滤」这一层防线在这里被正面挑战：当生成能力本身就是产品卖点，过滤就是与商业目标对冲的功能。这类案件的结果会决定平台责任的边界画在「模型能力」还是「分发行为」上。

**🌡️ COP31 谈崩：AI 用电成了气候谈判的暗礁**
安塔利亚的两周谈判未能通过协议，欧盟与英国认为草案过弱，文本中甚至省略了「化石燃料」，美国缺席。AI 数据中心令电力需求飙升被正式摆上议题：IEA 预计数据中心用电到 2030 年翻倍，Meta 因 AI 投入碳排放同比增加 45% 并重新评估净零时间表；约 80 国签署了到 2035 年把电力占能源消费比重提升至 35% 的自愿承诺。

这里的结构性矛盾很清楚：算力扩张的决策周期是季度，能源基础设施是十年，气候谈判是两年一轮且需要一致同意。三个时钟不同步，谁也不会等谁。

## 🇨🇳 国内动态

**🇨🇳 智谱 GLM-5.4：用循环 Transformer 拿深度，不拿参数**
智谱发布旗舰模型 GLM-5.4，是第一代采用 Loop Transformer 架构的模型：28 层共享权重循环执行两轮，在参数量不变的前提下获得更深的推理链，官方称智能水平达到 2–3T 级模型效果，并开启泛 Coding 能力。

这条路线值得单独看。在高端算力受限的现实约束下，「把同一批权重多跑一遍」比「把参数堆大」便宜得多，是典型的以架构换规模。但需要注意，2–3T 级效果是官方口径，目前没有第三方复测；循环深度带来的收益在长上下文与工具调用场景里是否同样成立，也需要实测。

**💰 DeepSeek 二轮融资落定：募资 140–150 亿美元，投后约 860 亿**
据 @X.PIN 汇总，DeepSeek 完成第二轮融资，投后估值约 860 亿美元；腾讯与宁德时代为最大外部投资者，各持股约 9.6%，中国移动与中信证券各约 7.7%。同一条信息里还有腾讯 WorkBuddy 的数据：截至 11 月初日活超 1000 万，日均 token 调用量达 100 万亿，称是中国日均 LLM token 用量最高的 AI 产品。

另一侧收紧的是披露义务：美国国会相关委员会建议要求上市公司在 SEC 文件中披露使用 DeepSeek、Qwen 等中国模型的情况。模型选型从技术决策变成需要向监管说明的采购决策，这会实质影响海外企业的选型意愿。

**📦 端侧小模型落地：MiniCPM 8B 成为老挝国家模型**
面壁智能披露，截至 2026 年 11 月 MiniCPM 下载量超过 7000 万；其 8B 老挝国家模型已接入老挝政府 G-Chat v2 通讯软件，老挝翻译在国际基准上超过 GPT-4o。马来西亚用 VoxCPM2 做语音交互，肯尼亚一家银行在其上运行端侧风控 Agent，另有开发者基于它推出离线应用。

竞争叙事的转向就在这里：从「谁的参数量大」变成「谁真正嵌进了日常系统」。政府通讯软件、银行风控、离线场景共同的特点是——数据不能出境、网络可能不可靠、成本必须极低，这恰好是端侧小模型的三个天然优势位。

**🚫 Megaspeed 或被列入实体清单，芯片路径再收紧**
新加坡云与 AI 基础设施公司 Megaspeed 可能被美国商务部列入实体清单，据 Semafor 援引匿名消息，此举意在阻止其获得美国制造的半导体；商务部上周已宣布对其启动刑事调查，美新双方正在核查是否违反出口限制，公司否认存在不当行为。这家公司正处于黄仁勋事件的舆论中心。

同日 NVIDIA 董事会撤销此前决定，恢复黄仁勋 CEO、总裁兼董事职务，特朗普亦公开表态支持，称政府没有其不当行为的证据。算力供给与治理两条线在同一个星期里同时震荡，对依赖跨境算力的团队来说，供应链的不确定性已是常态而非例外。

## 🧪 研究前沿

**🧬 0.1% 的预训练投毒，干净后训练洗不掉**
UC Berkeley、UIUC 与 Anthropic 的论文给出一个不太舒服的结论：污染 0.1% 的预训练文本即可在智能体里植入后门，且无法被干净的后训练清除。研究从零预训练 0.6B、1.7B、4B 的 Qwen3 模型，再用干净的 SFT、DPO 与 RL 构建 CLI 智能体；投毒文档伪装成普通 commit message，触发条件是当文件路径包含「anthropic」时执行远程脚本。

结论的含义超出单篇论文：如果后训练无法修复预训练污染，那么「数据来源可信」就不再是加分项，而是安全基线。使用来路不明的公开语料做预训练的团队，需要把数据溯源当作和权重加密同级的事。

**⚛️ Gemini 4 + Lean：量子算法最高提速 290 倍**
Google DeepMind 与 Google Quantum AI 用多组 Gemini 4 智能体协同优化量子算法，并用形式化定理证明器 Lean 对每个结果做数学验证，相关 Lean 库与已验证方案已在 GitHub 开源。据 IT之家报道，最高取得 290 倍提速。

这已经是两周内第三次「生成 + 机器可验证」在硬数学上给出可用产出（此前是黎曼猜想的 Lean 认证与 3SUM／APSP 的复杂度改进）。模式正在固化：模型的角色是搜索与构造，Lean 的角色是裁决。可验证的领域先被吃掉，不可验证的领域继续慢。

**🧠 MIT：21 种语言共享同一套神经编码**
MIT McGovern 研究所在 Nature Neuroscience 发表研究，用多语言大模型构建 encoding model 预测 21 种语言使用者的脑活动，发现人脑以共同方式处理不同语言；仅用单一语言训练的模型也能预测从未见过的语言的脑响应，共享成分可能与语义有关。潜在用途是两个方向：更包容的脑疾病诊断工具，以及濒危语言的保护。

**🧫 Claude 在病毒 DNA 里发现类 CRISPR 重复模式**
Anthropic 科学家在病毒 DNA 中识别出一段与 CRISPR 相似的重复模式，目前正在通过实验验证其工作机制是否类似。这里需要克制：CRISPR 从「细菌 DNA 里一种难以解释的重复序列」到机制被阐明，用掉了多年时间。模式相似只是起点，离「AI 发现了新的基因编辑工具」还很远。

## 💵 产业与资本速览

- **River API 五个月 ARR 破 1 亿美元**，今年有望超过 2 亿。微软 AI CEO Mustafa Suleyman 转发并称「初创智能的时代已经到来」；其自称是唯一开箱即支持前沿级 RL 训练规模的系统。RL 训练基础设施正在成为独立的高毛利层。
- **AI 理财初创 Supertake 完成 2000 万美元种子轮**，Adjacent 领投，Coinbase Ventures、Union Square Ventures 参投，产品让 agent 把用户的市场观点变成投资组合。这条赛道最缺的不是模型，是合规与受托责任——把「观点」变成「组合」在法律上属于投资建议。
- **Canva 发布 MCP 服务器**，任意 agent 可用一句需求依次调用 Canva 工具，生成设计、创建视频并适配各平台尺寸，最终返回可编辑的 Canva 设计文件交人工审核发布。设计工具正在从「人用的软件」变成「agent 调用的能力端点」。
- **Ladybird 浏览器发布首个 alpha**，macOS 与 Linux 用户首次可直接安装而无需自行编译；多标签按进程隔离，WASM 工具可正常跑。独立浏览器引擎仍有增量空间。
