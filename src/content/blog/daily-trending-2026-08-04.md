### 🚀 GitHub 热门项目

今天 GitHub Trending 上的热门项目（均为公开仓库，Star 增长快）：

1. **zhaoxuya520/reverse-skill**（2.4k★, PowerShell）— 逆向工程技能合集，涵盖脱壳、Hook、协议分析等方向，安全爱好者值得收藏，连续多日霸榜。

3. **microsoft/AI-For-Beginners**（1.9k★, Jupyter Notebook）— 微软出品的 AI 入门课程，覆盖神经网络、NLP、计算机视觉等核心主题，适合零基础系统学习。
4. **TencentCloud/TencentDB-Agent-Memory**（1.1k★, TypeScript）— 腾讯云 TencentDB 面向 AI Agent 的记忆组件，为智能体应用提供数据库侧的记忆与知识增强能力。
5. **lyogavin/airllm**（1.1k★, Jupyter Notebook）— 经典项目 AirLLM：无需量化和蒸馏，单张 4GB 显卡即可运行 70B 大模型，分层推理的实现思路值得学习。
6. **esengine/DeepSeek-Reasonix**（883★, Go）— 与 DeepSeek 推理能力相关的开源工具，Go 实现，适合想折腾推理服务的同学。
