### 🚀 GitHub 热门项目

今天 GitHub Trending 的主线依旧是**智能体工具链**，并且明显从「写代码」扩散到了「记忆、联网、视频、CAD」等更外围的能力层——智能体正在被装上五官和四肢。

1. **thedotmack/claude-mem**（TypeScript，★96.7k）——为每个智能体提供跨会话的持久上下文：把会话里发生的一切压缩归档，下次开聊不用从零开始，连续多日霸榜。
2. **Panniantong/Agent-Reach**（Python，★91.9k）——给 AI 智能体一双「看遍全网」的眼睛，一个 CLI 即可读取检索 Twitter、Reddit、YouTube、GitHub、Bilibili、小红书，零 API 费用。
3. **caddyserver/caddy**（Go，★77.1k）——老牌常青：自动 HTTPS 的多平台 HTTP/1-2-3 Web 服务器，今天重新回到热榜。
4. **calesthio/OpenMontage**（Python，★64.1k）——号称全球首个开源「智能体化」视频生产系统：12 条生产流水线、100+ 工具、700+ 智能体技能与制作知识文件。
5. **pingdotgg/t3code**（TypeScript，★25.6k）——pingdotgg（t3.gg）出品的编码相关新项目，带着社区热度直接冲榜。
6. **earthtojake/text-to-cad**（Python，★17.4k）——「给你的智能体一副 CAD 超能力」：用自然语言直接生成 CAD 模型。
7. **boykopovar/AnyPS5**（C++，★5.0k）——把 PS5 可执行文件自动移植到 Linux 与 Windows 的工具。
8. **tester-army/e2e**（TypeScript，★4.9k）——面向 Web 与移动端的下一代端到端测试框架。

一句话概括今日热榜的走向：**上层的「智能体技能」已经被卷完了，大家开始卷记忆层、感知层和垂直生产力工具。**
