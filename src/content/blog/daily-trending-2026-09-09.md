### 🚀 GitHub 热门项目

今日 Trending 关键词：**Agent 技能(Skills)生态大爆发**——从"工具"卷到"方法论"，AI 写码的打开方式正在被重新定义：

- **ayghri/i-have-adhd**（Python，30.7k★）— 专治"答案被埋没"：让 coding agent 输出更聚焦、更 ADHD 友好的技能包。
- **cathrynlavery/diagram-design**（HTML，34.9k★）— 38 种编辑级图示模板，纯 HTML+SVG 自包含输出，无阴影、无 Mermaid"糊图"，适配 Claude Code / Codex。
- **openai/skills**（Python，26.5k★）— OpenAI 官方 Codex Skills 技能目录，Agent 技能生态的官方"货架"。
- **heygen-com/hyperframes**（TypeScript，47.8k★）— 写 HTML 直接渲染成视频，面向 Agent 的"网页即分镜"。
- **microsoft/markitdown**（Python，181.7k★）— 微软出品：办公文档/文件批量转 Markdown，喂给 LLM 前的处理利器，常驻热榜。
- **browser-use/browser-use**（Python，113.5k★）— Agent 用浏览器的最流行开源方案，浏览器自动化玩法标杆。
- **jo-inc/camofox-browser**（JavaScript，10.5k★）— 隐身无头浏览器：帮 AI Agent 绕过 Cloudflare 与反爬/机器人检测，Puppeteer/Playwright 平替。
- **viarotel-org/escrcpy**（JavaScript，11.4k★）— 图形化 scrcpy：在电脑上无线投屏/控制 Android 手机的开源工具。
