今天的三条主线分别是：手机侧 Agent 的入口被 Apple 重新定义，前沿实验室第一次拿出接近盈利的财务叙事，以及开源权重模型在编码任务上把「同水平、十分之一价格」变成了可复现的实测结论。

## 🇨🇳 国内 AI 动态

### 🧠 小红书 AllSpark 开源 Iris：Search Agent 小模型开始追平大模型

小红书 AllSpark 团队发布并开源 Search Agent 模型 Iris，同步公开权重与评测代码，数据与训练配方将陆续公布。Iris 提供 35B 与 397B 两个版本，官方称两者在同量级对比中成绩领先——换言之，35B 版本已能对齐更大参数量的同代方案。

**为什么重要**：搜索型 Agent 是 Agent 落地中最「重工具调用」的一类，长期依赖闭源大模型加自研检索栈。把权重与评测一起放出，意味着这块能力开始进入可复现、可自托管的阶段。**影响**：中小团队可以用 35B 级别模型搭建自己的联网检索 Agent，成本结构从按次付费转为一次性部署；不过官方留了「数据与配方稍后公布」，训练侧的复现难度仍要看后续进展。

### 🛠️ 硅基流动上线 Hy4 preview：770B 总参数、1M 上下文

硅基流动宣布开源模型 Hy4 preview 上线其平台。该模型总参数 770B、每 token 激活 49B、支持 1M 上下文，采用 Apache 2.0 协议，定位编码、分析、研究与复杂实际工作。官方定价为每 1M tokens 输入 $0.834、输出 $2.501、缓存 $0.042，并明确用户可将其接入 Claude Code、Codex、Cursor 等现有工具链。

**为什么重要**：770B 总参数配 49B 激活，是典型的「大容量、低激活」路线；1M 上下文叠加分层定价（缓存价约为输入价的 1/20），直接对标的是长会话编码 Agent 这个最烧 token 的场景。**影响**：开源权重加低价托管的组合继续压缩闭源模型的定价空间，也让「换后端不换工具」成为常态操作。

### 🏭 DeepSeek-V4.1-Flash（Max）进入 Agent Arena 开源榜第 3

Arena 数据显示 DeepSeek-V4.1-Flash（Max）进入 Agent Arena 开源模型第 3 名，净提升 +4.87%，每任务中位成本 $0.07，重塑了该榜单的 Pareto 前沿。其成本比第 2 名 Hy4 preview 低 68%，成绩仅差 0.09 个百分点；在总榜排名第 12，其中「Confirmed Success」信号排名第 4（+13.75%）。

**为什么重要**：Agent 评测的排序正在从「谁最强」转向「每美元能买到多少成功率」。在 Confirmed Success 这个更严格的信号上名次反而更高，说明它的优势并不只是便宜。**影响**：对做编码与工具调用 Agent 的团队而言，V4.1-Flash 已经进入「默认基线」候选，任何新方案都要先回答「比它贵几倍、强多少」。

## 🌍 国际 AI 动态

### 🛠️ Apple 发布新一代 Apple Intelligence：Siri AI 以英文测试版上线

Apple 发布新一代 Apple Intelligence，推出全面重构的 Siri AI，支持个人语境理解、屏幕感知、系统级应用操作与跨设备对话。今日起随 2027 系统更新以英文测试版推出，下月扩展至法语、日语、韩语、葡萄牙语和西班牙语。

**为什么重要**：屏幕感知加系统级应用操作，明确把 Siri 从「问答助手」推向「设备 Agent」，这也是 Apple 第一次在系统层开放跨 App 的操作能力。**影响**：真正的变量是语言与地区节奏——英文先行、中文未列入首批，国内用户的可用时间仍不明确；而个人语境理解如何处理本地数据，会成为后续隐私讨论的焦点。

### 🏭 Anthropic 计划登陆纳斯达克：连续第二季度盈利，瞄准 2 万亿美元估值

据 The Decoder 报道，Anthropic 已告知投资者将实现连续第二个季度盈利，但该口径基于剔除股权激励等成本的调整后指标；据 Financial Times，其毛利率超过 80%，且尚未计入对 Amazon 等伙伴的分成与模型训练成本。公司正瞄准约 2 万亿美元估值推进 IPO。

**为什么重要**：这是前沿实验室第一次拿出「接近盈利」的财务叙事，但「调整后盈利」与「扣除伙伴分成和训练成本后是否盈利」是两个不同的问题。**影响**：一旦上市，Anthropic 的定价、算力采购与安全表态都会开始受公开市场信号约束；而 2 万亿估值若成立，会重估整个上游算力与云厂商的资产价格。

### 🧠 Fireworks 评测 DeepSeek-V4.1-Flash：DeepSWE 达 GPT-6 Astra 水准，成本约 1/15

Fireworks 发布 DeepSeek-V4.1-Flash 并公开完整基准结果：在 DeepSWE 上以 max 档取得 74.34% pass@1，与 GPT-6 Astra 处于同一水平，但每任务成本 $0.43，约为 Astra 的 1/15。

**为什么重要**：第三方托管平台的独立评测比厂商自测更有说服力，且它给出了「同水平、不同成本」的直接对照。值得注意的是评测使用了 max 推理档，即已包含更多思考 token 的开销，仍保持一个数量级的价差。**影响**：编码 Agent 的单位经济性正在被重新划线——如果同水平能力价差达到 10 倍以上，闭源模型的溢价将越来越依赖工具链与工程集成，而非模型本身。

### 💡 Artificial Analysis 上新 Speech to Speech Index：GPT-Live-1 以 81.5 分登顶

Artificial Analysis 发布 Speech to Speech Index，OpenAI 的 GPT-Live-1 以 81.5 分（Astra 后端、medium 推理强度）排名第一，超过 Grok Voice Think Fast 2.0 High 的 81.3；同一模型的 Sol 后端配置得 80.1 分，排第三。

**为什么重要**：语音端到端此前缺少统一榜单，各家只能拿演示案例说事。有了指数之后，「哪家语音更自然、更抗打断」第一次可以横向比较。**影响**：语音交互的调用成本已压到 $0.05/分钟的区间，榜单出现会让竞争从演示转向可测指标，也会把「后端模型选择」变成用户可调的旋钮。

### 💡 放缓前沿是安全共识还是卡特尔：The Verge 提出质疑

Sam Altman、Dario Amodei、Demis Hassabis 与 Elon Musk 在周末粗略同意放慢 AI 开发，提出引入第三方审计、监管国内实验室并达成全球放缓协议。批评者认为这套安排更像压制竞争者与开源运动的「卡特尔」，而非单纯的安全共识。

**为什么重要**：判断标准其实很具体——放缓是否附带可验证的第三方审计、是否对自建算力的小型实验室同样适用。若只有头部几家坐下来「约定节奏」，就难免被读成供给侧协调。**影响**：这一轮表态已经把「安全」和「竞争」绑进同一份文件，监管介入方式将决定它是行业自律还是新的进入壁垒。Tomer Tunguz 的补充分析把这轮争论拆成可解释性、劳工、经济、地缘政治、监管俘获五派立场，并指出没有任何一派给出具体速度——而这恰恰是最关键的空缺。

### 💡 Anthropic 自述 CI 压力：季度代码量 8 倍、80% 由 Claude 编写、CI 任务半年涨 25 倍

Anthropic 工程团队发文说明如何重构「测试影响分析」服务，以应对智能体编码带来的 CI 压力：工程师每季度交付的代码量达到 2021—2025 年均值的 8 倍，其中 80% 由 Claude 编写，六个月内 CI 任务增长 25 倍。

**为什么重要**：这是目前少见的、来自前沿实验室内部的量化数据，它量化了智能体编码对下游基础设施的乘数效应——代码产出 8 倍，CI 负载却涨 25 倍。**影响**：AI 编码的瓶颈已从「写得出来」转移到「验得过来」。测试选择、增量验证、CI 并行度这类看似枯燥的工程投入，会直接决定 Agent coding 的真实产能。

### 🔐 RubyGems 恶意 gem 技术复盘：YARD 的 --load 成了任意代码执行入口

安全研究者对与 OpenAI 机器人相关的 GemStuffer 恶意 gem 代码做了技术分析，发现其利用 .yardopts 中的 --load 参数加载脚本，在安装过程或 RubyDoc.info 处理 YARD 文档时执行任意代码；同时 Docker 容器具备网络访问权限，可进一步执行爬取行为。

**为什么重要**：攻击面不在 Ruby 包管理器的安装钩子，而在文档工具链——这类周边工具通常不进入供应链审计的视野。**影响**：依赖链的审计边界需要外扩到文档、类型检查、格式化工具；对 CI 环境而言，「构建容器默认可联网」这条默认设置，才是这次事件真正放大的部分。

### 💡 一个 $1.20 的模型够不够做代码评审：Luna 与 Astra 的成本-精度对照

Entelligence 在 50 个公开基准 PR 上，用相同提示词对比 GPT-5.6 Luna 与 GPT-6 Astra 的代码评审能力：Luna 找到 69 个经验证 bug（Astra 为 92 个），总成本 $0.20 对 $5.66，精度 74% 对 96%。

**为什么重要**：它把「该用哪个模型」变成一道可计算的题——Astra 多找出 23 个真 bug，代价是约 28 倍花费。精度差 22 个百分点，召回差约 25%，最终取决于漏掉的那些 bug 值多少钱。**影响**：代码评审可能是最适合分层模型的场景：小模型全量扫描、大模型只处理可疑项。这与 Anthropic 那篇 CI 文章的结论指向同一方向——算力要花在验证上，而不是均匀撒开。
