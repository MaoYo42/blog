今天的 Trending 榜单几乎没有纯做模型的项目，前排清一色是围绕 Agent 的工程件——审计、压缩、编排、省钱。这个信号很明确：模型能力已经不再是瓶颈，成本与可信度才是。

## 🚀 GitHub 热门项目

- **[DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)** · JavaScript · 171,746 ★
  让 AI Agent 像「最懒的资深工程师」那样思考。核心思路是用最少的代码解决问题，对抗 Agent 天然的过度工程倾向。

- **[Comfy-Org/ComfyUI](https://github.com/Comfy-Org/ComfyUI)** · Python · 141,565 ★
  最强大的模块化扩散模型 GUI / API / 后端，节点式图工作流，本地出图的事实标准。

- **[supabase/supabase](https://github.com/supabase/supabase)** · TypeScript · 113,040 ★
  Postgres 开发平台，一个项目里给你数据库、认证、存储、实时订阅和边缘函数，开源自托管友好。

- **[stablyai/orca](https://github.com/stablyai/orca)** · TypeScript · 101,363 ★
  用自有订阅跑一整支编码 Agent 舰队的工作台，支持桌面 / 移动 / 远程，多个 Agent 并行不打架。

- **[vllm-project/vllm](https://github.com/vllm-project/vllm)** · Python · 94,907 ★
  高吞吐、显存高效的 LLM 推理与服务引擎，PagedAttention 的老家，自建推理绕不开的项目。

- **[headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom)** · Python · 77,288 ★
  在工具输出、日志、文件、RAG 分块进入 LLM 之前先做压缩。直接对着上下文成本下手。

- **[twentyhq/twenty](https://github.com/twentyhq/twenty)** · TypeScript · 59,208 ★
  面向 AI 设计的 Salesforce 开源替代，CRM 该有的都有，还能自己改。

- **[shiyu-coder/Kronos](https://github.com/shiyu-coder/Kronos)** · Python · 42,857 ★
  金融市场「语言」的基础模型，把 K 线当序列来建模，量化研究值得看一眼。

- **[cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)** · JavaScript · 36,624 ★
  多阶段安全审计的编码 Agent 技能包，要求审计结论可独立复核且机器可读。

看完这份榜单，一句话概括：**在给 Agent 装刹车和记账本**。
