## 🚀 GitHub 热门项目

按今日新增 star 排序（已剔除 5 个 sponsors 赞助位）：

1. **XiaoYouChR/Ghost-Downloader-3**（Python，+1,078）— 多线程下载器第三代，前两期同样在榜，说明是「装机必备」型热度，而非单日爆发。
2. **firecrawl/firecrawl**（TypeScript，+920）— 给 Agent 的知识基础设施：搜索、抓取、解析，一个 API 打通 550+ 数据源。
3. **zhouxiaoka/autoclip**（Python，+908）— 长视频一键切成短视频，自动出字幕、封面与文案，中文项目。
4. **jingyaogong/minimind**（Python，+828）— 两小时从零训出 64M 参数小模型，适合拿来理解训练全流程而不是拿来卷效果。
5. **mvanhorn/last30days-skill**（Python，+790）— Agent 技能：跨 Reddit、X、YouTube、HN、Polymarket 与网页做「近 30 天」话题调研并出有出处的综述。
6. **HKUDS/CLI-Anything**（Python，+783）— 把任意 CLI 封装成 Agent 原生接口，配 CLI-Hub 分发，口号是「让所有软件都对 Agent 友好」。
7. **Tracer-Cloud/opensre**（Python，+438）— 面向 CI/CD 与线上故障的可靠性 Agent。
8. **google-labs-code/stitch-skills**（TypeScript，+425）— Google Labs 的 Stitch 相关技能集。
9. **cursor/plugins**（TypeScript，+395）— Cursor 官方插件规范与插件仓库。
10. **openvinotoolkit/openvino**（C++，+183）与 **nginx/nginx**（C，+174）— 两个老牌基建回到榜内，做端侧推理优化与官方源码。

读榜结论：前六里有四席在解决同一个问题——**Agent 缺的不是智力，而是「能摸到东西、能查得到东西」的手和眼**。抓取层、CLI 适配层、调研技能、剪辑流水线，本质都是把外部世界转成 Agent 可消费的接口。
