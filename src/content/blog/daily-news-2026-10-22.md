> 今天的主线是「速度差」。AI 用两天时间挖出了潜伏十几年的 PHP 底层漏洞——两个 CVSS 9.2 的远程代码执行，影响范围可以追溯到 PHP 5.4，覆盖全球约 70% 的网站；而从泄密、演示视频外流、多国政府网站预防性下线，到补丁真正上线，人类花了两个月。NSA 在补丁发布后仍要发警告催人升级，Wiz 同时捅出 LiteLLM 的 PyPI 投毒。另一头，钱的速度同样不讲道理：DeepSeek 一轮融 150 亿美元、Anthropic 最快本周五递表、马斯克想把 SpaceX 和 Tesla 合成一个 AI 公司。当「发现」以天为单位、「修复」以月为单位、「估值」以小时为单位，真正的问题就不再是谁更强，而是谁来得及。

## 🌍 国际动态

### 🛡️ PHP2Shell：AI 两天挖出的 0-day，人类修了两个月

安全公司 Calif 的研究人员用 GPT-5.6 Sol 在 PHP 核心中发现了两个远程代码执行漏洞，编号 CVE-2026-109618 与 CVE-2026-109619，CVSS 评为 9.2，合称 PHP2Shell。漏洞位于 PHP 引擎本身，攻击者无需任何账号即可接管 Web 服务器；在 Apache mod_php 上演示的利用方式可以在应用代码运行之前就触发，影响版本至少追溯到 PHP 5.4，Wiz Research 估计波及全球约 70% 的网站。

时间线是这件事最刺眼的部分：发现只用了两天，修复用了两个月。补丁发布前漏洞细节已经泄露，攻击演示视频外流，多国政府网站选择预防性下线；10 月 21 日晚 10 点补丁上线，NSA 紧接着发布修复警告，敦促组织打补丁或者把未修补的服务器直接下线。OpenAI 把这轮工作归入「Patch the Planet」计划，牵头维护者、研究者与安全厂商组成联盟，Wiz 独立发现了同样两个漏洞，PHP 维护者主导修复与发布——这次修复涉及 PHP 引擎的深层改动，而不是一个补丁包能解决的小问题。

意义在于攻防节奏的错位。AI 把漏洞挖掘的边际成本压到了接近零，挖出 0-day 的速度从「月」变成「天」；但一个漏洞从确认到全球升级完成，仍然受制于发版流程、下游发行版同步、企业变更窗口这些人类时间。**当发现速度快过修复速度一个数量级，漏洞的数量就会开始堆积，而不是被清空。** 对普通站长的直接动作只有两个：把 PHP 升到修复版本，或者用 OpenAI 开源的 `php2shell-checker` Codex 技能自查一遍。（来源：Wiz Research、OpenAI、NSA 警告 via Rohan Paul）

### 📦 LiteLLM 被投毒：PyPI 上的一个版本，够偷走所有模型密钥

同一天，Wiz 披露了另一条更"日常"的攻击路径：10 月 21 日 11:39 UTC，恶意版本 LiteLLM 1.107.0 被上传到 PyPI，用来窃取凭据；1 小时 41 分钟后被隔离，GHCR 与 Docker Hub 上对应的镜像标签也被植入，约 13:53 UTC 移除，最后的安全版本是 v1.106.2。

LiteLLM 是无数团队统一调度多家模型 API 的中间层，这意味着它天然握着 OpenAI、Anthropic、Gemini 等一长串密钥。攻击者不需要攻破任何模型厂商，只要在这个"钥匙串"上放一个版本就够了。**AI 基础设施的供应链风险，本质上已经从"代码漏洞"迁移到"依赖信任"**——你审不了每一行第三方代码，但你至少该锁版本、校验哈希、把密钥做成短期凭证。任何在 10 月 21 日白天拉过 `litellm==1.107.0` 或对应镜像的环境，都应当视为已泄露。（来源：Wiz Research）

### 💰 DeepSeek 单轮融资 150 亿美元，六个月共募 225 亿

Bloomberg 报道，DeepSeek 最新一轮融资规模约 150 亿美元，是中国最大规模的私募融资之一。谈判期间目标至少两次上调——从约 75 亿美元抬到 120 亿美元，最终落在 150 亿；宁德时代与腾讯是最大投资方，其中宁德时代据报出资约 15 亿美元。投前估值约 748 亿美元，加上 6 月完成的首轮超 75 亿美元，DeepSeek 在约六个月内共募资约 225 亿美元。

值得注意的不是数字本身，而是出资方的构成：一家动力电池巨头加一家社交与云厂商，而不是传统 VC。这意味着中国的模型竞赛正在把产业资本直接拉进算力与电力的循环里——电池厂有能源侧的资源，云厂商有场景和流量，两边都在为"下一个十年的基础设施"下注。相对地，748 亿美元的投前估值放在全球看仍显著低于 OpenAI 与 Anthropic 的量级，这既是折价，也是它保持低价 API 的空间所在。（来源：Bloomberg via Rohan Paul）

### 📄 Anthropic 最快本周五递表，或创史上最大 IPO

雅虎财经援引知情人士称，Anthropic 最早可能在本周五公开提交 S-1 招股说明书，推进一桩有望创下史上最大规模的 IPO。此前 WSJ 看到的草案显示，公司上半年收入 163 亿美元、纸面亏损 807 亿美元、承诺约 4500 亿美元算力支出，同时难以从 AWS、Google、微软获得足够算力——三家云厂商正日益把它当竞争者而非客户。

从"草案泄露"到"正式递表"只隔了一天，这个节奏说明窗口期判断已经非常紧迫：OpenAI 正在抢跑洽谈 3000 亿美元融资，DeepSeek 刚把中国市场的资金抽走一大块，谁先把估值钉在公开市场上，谁就拿到下一轮算力采购的定价权。对行业的连带影响是，S-1 会把模型公司的单位经济模型第一次完整摊开给公众看：每美元收入对应多少算力支出、毛利率的真实形状、以及那 4500 亿承诺怎么摊销。这些数字会比任何基准分数更能决定 2027 年的融资环境。（来源：Yahoo Finance via IT之家、WSJ）

### 🚀 马斯克想把 SpaceX 和 Tesla 合成一个 AI 公司

WSJ 报道，马斯克希望以 AI 为核心推动 SpaceX 与 Tesla 合并，两家当前估值分别约 2 万亿美元与 1.5 万亿美元。支撑这个想法的财务事实是：SpaceX 的 AI 业务已经成为它最大的业务，Q3 营收 75.6 亿美元（一年前仅 8.13 亿美元），季度 196 亿美元资本开支中有超过 164 亿投向 AI，并推动公司实现 44 亿美元季度利润（上年同期亏损 10.5 亿）。

把两件事放在一起看，逻辑其实很直白：一边是需要海量电力与机架的算力生意，一边是握着储能、电控、自动驾驶数据与量产能力的制造公司。合并的实质不是业务协同，而是**把能源与制造能力并进 AI 资产负债表**，让算力扩张不再受外部供电与设备交付的约束。当然，2 万亿加 1.5 万亿的合体在任何监管辖区都是一场硬仗，这更像一个方向性信号：AI 基础设施的竞争单位，正在从"公司"变成"产业集团"。（来源：WSJ via Rohan Paul）

### ☁️ OpenAI 的模型进了 Google Cloud 的 Model Garden

OpenAI 与 Google Cloud 达成合作，把 OpenAI 的前沿模型与 Codex 智能体工作流引入 Google Cloud 的 Model Garden，客户可通过 Google Cloud Marketplace 购买，并可用 GCP 消费承诺抵扣。

这条新闻的分量在于身份的反转：一年前这两家还是正面对手，如今 OpenAI 的模型成了 Google Cloud 的货架商品。对采购方而言这是好事——原本沉淀在 GCP 上的承诺消费可以直接用来买 GPT，云迁移的摩擦大幅下降；对 Google 而言，它把"卖算力"放在了"卖自家模型"之前，这与 Anthropic 抱怨"云厂商把我当竞争者"是同一枚硬币的两面。**云厂商正在退回到基础设施角色，而模型公司被迫在全栈上自己动土。**（来源：OpenAI）

### 🎬 可灵 Kling 4.0 上线：30 秒原生、21:9、15 张参考图

可灵宣布 Kling 4.0 已在 OnSolo 上线。核心升级是单次生成 30 秒原生视频，快速动作与大运镜下保持稳定，立体声配更准的口型同步，并提供 21:9 宽银幕；单个任务最多可叠加 15 张参考图与 10 个关键帧，用于保持角色、镜头与剧情的一致性。

从产品定义看，这一代的目标已经从"生成好看的片段"转向"生成可用的镜头"。30 秒加多关键帧加宽幅，正好对应短剧与广告的分镜单位；一致性约束（参考图 + 关键帧）解决的则是系列化生产里最贵的返工问题。**视频模型开始按"剪辑台"而不是"玩具"来设计参数**，这也解释了为什么国内算力消耗里视频生成占比一直居高不下——需求端确实在生产，不只是尝鲜。（来源：Kling AI）

### 🤖 Claude Duet：Anthropic 让 Claude 变成主动式智能体

Anthropic 开启 Claude Duet 研究预览，这是一款让 Claude 作为主动式智能体工作的独立应用，已登陆 iOS、Android 与 claude.ai，面向美国 Pro 与 Max 用户开放候补名单。

"主动式"三个字是重点：过去的对话产品等你提问，Duet 的形态是按目标持续工作、自己决定下一步。这与 OpenAI 的 Codex、Google 的 Project 系列在同一方向上，区别在于 Anthropic 把它做成了独立应用而不是嵌进聊天框——腾出界面空间给"任务列表与执行状态"，也就默认了这类产品的核心体验是监督而非对话。真正待验证的是 OpenAI 前几天自曝的那类问题：当 agent 自主运行时，用户如何确认它实际做了什么。主动性的代价是可追溯性。（来源：Claude Blog）

### 🧮 Baseten 开源决策模型 mammoth-1 与 elephant-1

Baseten 的研究实验室 Base Labs 发布两个开源决策模型：mammoth-1（27B）与 elephant-1（9B），分别基于 Qwen3.5-27B 与 Qwen3.5-9B，在 621 万条决策样本上后训练而成，开源并免费试用一周。

"决策模型"是一个正在成型的品类：它不追求写文章或写代码，而是给定状态与约束输出动作，典型场景是定价、排产、风控与调度。这个方向的价值在于可评测性——决策的对错有客观回报信号，不像开放式生成那样只能靠人打分。用 Qwen 底座做后训练也说明一件事：**在垂直决策任务上，后训练数据质量比底座参数规模更能决定上限**，27B 能打到什么程度，会比榜单分数更值得看。（来源：Baseten 工程博客）

## 🇨🇳 国内动态

### 📜 商务部第 48 号公告草案：40 项技术入管制目录，23 项涉 AI

ChinaTalk 详读了中国商务部与科技部 10 月 16 日发布的第 48 号公告草案：拟向《中国禁止出口限制出口技术目录》新增 40 项技术，其中 14 项禁止出口、26 项需许可，23 项涉及 AI。

这是本轮 AI 治理里最容易被低估的一条。出口管制的对象通常不是"模型权重"这种可以复制的东西，而是**know-how 与工艺**：训练方法、蒸馏流程、推理优化、特定硬件适配经验。一旦落入许可清单，中国企业海外建团队、联合研发、技术授权、甚至部分开源协作的合规成本都会上升。ChinaTalk 的解读强调，这份草案与美国的算力管制形成了镜像结构——一边卡芯片，一边卡方法。对国内从业者的现实影响是，跨境技术合作的合同条款需要重新审一遍，尤其是涉及人员派驻与联合训练的部分。（来源：ChinaTalk）

### 🔋 宁德时代与腾讯入局 DeepSeek：产业资本开始买模型

承接前文的 150 亿美元融资，出资结构值得单独看：宁德时代据报出资约 15 亿美元，腾讯为最大投资方之一。对一家模型公司来说，这两类股东带来的不是钱，而是两类稀缺资源——能源与分发。

算力扩张的瓶颈已经从芯片转向电力与机架交付，电池与储能企业的入场意味着能源侧可以被"内部化"；而腾讯的流量与云基础设施则提供了场景入口。**这与美国那边"云厂商既是股东又是竞争者"的紧张关系形成有趣对比：中国的模型公司正在把股东结构做成供应链。** 代价是独立性，DeepSeek 未来在开源策略上是否还能保持过去那种"全开放"的姿态，会是观察点。（来源：Bloomberg via Rohan Paul）

## 📄 论文与研究速览

- **Microsoft Research 证明 31 年的 KLS 猜想**：Xinzhi Zhang 与 Zhao Song 证明了 1995 年提出的 Kannan–Lovász–Simonovits 猜想——对数凹分布的最优平面切割与任意形状切割之间只差一个普适常数，且这个差距不随维度增长。它的意义在算法侧：对一大类凸优化问题，"低维切片"可以替代"全维求解"而不损失阶数，直接对应采样与体积计算的复杂度下界。
- **OpenAI、PerturbAI 与 Scripps 用数千个 GPT-Rosalind 智能体 32 分钟扫完脑细胞图谱**：并行分析数百万个小鼠脑细胞的全脑 CRISPR atlas，完成分析与文献解读，官方称人工逐一分析需数月至一年。这类工作的价值不在"快"，而在把全量数据从"抽样研究"变成"普查"——样本量本身就会改变能提出的问题。
- **Google Research 的盲扫超声孕周评估**：在 JAMA Network Open 发表前瞻性多中心研究，评估基于"盲扫"（不依赖操作者标准切面）的 AI 孕周模型在不同临床环境与设备上的泛化能力，准确性与专家操作相当。对基层产科的意义是降低对超声技师水平的依赖，而泛化性恰恰是这类模型最难过的一关。
- **Anthropic 用 Claude 缩减开源代码攻击面：25 个项目、500 万行代码、493 个问题**：用默认配置、配置交互与早期可达性三种方法自动排查，产出的是"可被利用的配置路径"而不是泛泛的代码异味。与 PHP2Shell 放同一天看，这是同一趋势的另一面——AI 既在扩大攻击面发现能力，也在被用来收缩它。

## 💡 今日观察

**今天所有新闻都可以归到同一个词：速度差。**

AI 找漏洞用两天，人类修漏洞用两个月；DeepSeek 六个月募完 225 亿美元，而一家传统制造业公司走完同样流程要好几年；Anthropic 从草案泄露到递表隔一天；马斯克想把两家合计 3.5 万亿美元的公司合体，理由是"AI 业务已经是最大业务"——所有这些数字都在说，执行的速度已经被算力重新标定，而治理、修复、审计的速度还停在人类流程的节拍上。

PHP2Shell 是这个速度差最完整的样本。它同时展示了 AI 的两面：一面是发现能力——GPT-5.6 Sol 两天挖出潜伏十几年的引擎级漏洞，这在过去是顶尖团队几个月的工作量；另一面是攻击面的扩大——一个影响 70% 网站的核心漏洞，从泄露到补丁上线之间，全球有几十万个站点处于无防护状态，政府站点只能靠下线自保。而 OpenAI 同一天发布的，是一个让用户自查是否受影响的 Codex 技能。发现者、修复者、受害者、检查工具，全部挤在 48 小时里。

更值得警惕的是，这类事件会越来越常态化而不是越来越罕见。当漏洞挖掘的边际成本接近零，0-day 的供给曲线会整体右移；而修复侧的产能受制于发版周期与人力，几乎不可能同比例扩张。**这意味着未来的安全基线不是"没有漏洞"，而是"发现到利用之间的时间窗有多短"。** 对个人和小团队，能做的只有三件无聊但有效的事：锁依赖版本并校验哈希、把密钥换成短期凭证、以及保持升级通道畅通——LiteLLM 那次投毒就是最好的注脚，攻击者甚至不需要一个 0-day。

资本侧的叙事同样在加速，但方向相反：钱在以创纪录的速度集中到少数几家手里，而集中的理由恰恰是"算力太贵"。DeepSeek 拉来电池厂和腾讯，Anthropic 把云厂商的竞争关系写进招股书，OpenAI 的模型摆上了 Google Cloud 的货架，马斯克想把能源与制造并进 AI 资产负债表——四件事的共同点是，模型公司都在想办法把外部依赖变成内部资产。这不是技术竞争，是产业结构重排。

所以今天真正的问题不是"谁的模型更强"。当发现比修复快、融资比监管快、扩张比供电快，任何一方的优势都是暂时的，唯一稳定的是那三个时间常数之间的比例。谁能把这三个速度调平，谁才有资格谈护城河。
