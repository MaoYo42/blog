## 🤖 AI 大模型动态

**NVIDIA 连发多款 Nemotron 系列模型** — NVIDIA 发布 Nemotron 3.5 Content Safety，基于 Gemma 3 4B IT 的多模态安全评估模型，支持 128K 上下文，可通过自然语言自定义安全策略，覆盖 12 种显式训练语言并零样本泛化至约 140 种语言。同期发布的 Nemotron 3 Ultra 专为长时间运行的 AI 智能体优化推理效率，Nemotron 3.5 ASR 则以 600M 参数实现 40 种语言的流式语音识别。

**Nex-N2-Pro 发布：397B MoE 推理模型达 GPT-5.5 级别** — neolab 推出基于 Qwen3.5-397B-A17B 的 Nex-N2-Pro 推理模型，总参数 397B，支持 262K 上下文与多模态，性能对标 GPT-5.5 和 Claude Opus 4.7。模型可自动调节推理深度，减少 30-50% 思考 token 且无性能折损，硅基流动已提供免费试用支持。

**Google 发布实时音乐模型 Magenta RealTime 2 (MRT2)** — 该模型可通过 MIDI 键盘、实时文本提示甚至手势进行演奏，在 MacBook 上原生运行延迟低于 200ms，提供开放权重与开源推理引擎。

**OpenAI 称 AI 递归自我改进（RSI）迹象初现** — OpenAI 指出 AI 开发本身正被 AI 加速，这可能导致开发者与国家间竞争加剧，社会需要找到塑造 AI 发展轨迹的方法确保其服务于人类利益。

**DeepSeek 连续四周登顶 OpenRouter Token 份额榜** — 以实际使用量证明其市场地位依旧稳固。

**Boson AI 与 LMSYS 发布 Higgs Audio v3 TTS** — 基于 Qwen3-4B 骨干的约 4B 参数端到端语音合成模型，支持 100+ 种语言，20+ 种情感实时调节及流式合成。

**微软 AI 负责人称 Anthropic 模型太贵，正自研替代方案** — 微软 AI 部门表示 Anthropic 模型成本过高，正在内部研发更廉价的替代模型。

**OpenJarvis：本地优先的个人 AI 智能体框架** — Stanford 研究人员发布开源框架，在设备端运行推理、智能体、记忆与学习，与云端模型性能差距在 3.2 分以内，API 成本降低约 800 倍。

**OpenRouter 测试 11 款 LLM 实时决策能力** — Claude 和 Grok 系列在需要即时反应的智能体任务中表现突出，传统静态 benchmark 无法反映真实决策能力。

## 🔧 科技产品与行业

**Replit Agent 联手 Shopify 快速建店** — 开发者只需描述卖什么，Replit Agent 即可自动构建自定义店铺页面、创建 Shopify 商店并添加商品，几分钟内从想法到上线。

**ChatGPT 推出 Dreaming 记忆系统** — 新系统能更有效地记住用户偏好，在跨对话场景中保持上下文的新鲜感和相关性，进一步提升个性化体验。

**Gemini macOS 双击 Command 附加活动窗口** — 用户只需同时按下两个 Command 键，即可将当前活动窗口无缝附加到聊天中，无需手动截图。

**NotebookLM 来源归属功能上线** — 用户现在可查看每个创作物背后的提示词与来源，并支持"迭代"定制。

**Codex 推出 iOS 应用构建插件** — 集成 SwiftUI 预览和热重载编辑功能，Codex 用户可直接在应用内浏览器测试 iOS 应用。

**OpenAI API 新增内容审核评分** — 在 Responses API 和 Completions API 中返回审核信号，支持记录、路由、审核或拦截。

**Anthropic 开源 AI 驱动漏洞发现框架** — 代码托管在 GitHub 上，帮助识别软件中的安全缺陷。

**Cloudflare Radar：机器人流量首超人类占比 57.5%** — 过去一周全球 HTML 请求流量中仅 42.5% 来自真人浏览器，互联网流量主体已从人类浏览转向机器间通信和爬虫抓取。

**台积电：AI 需求产能压力巨大，美国本土产能建设需"非常长的时间"** — 全球最大芯片制造商表示难以跟上 AI 需求的爆发式增长。

**联合国报告：2030 年 AI 数据中心水电消耗将翻倍** — 去年全球数据中心耗电 448 太瓦时，到 2030 年预计翻倍至 945 太瓦时，碳排放将升至 3.99 亿吨，占地扩展至 14500 平方公里。

**GitHub Universe 2026 回归** — 将于 10 月 28-29 日在旧金山举行，主题聚焦智能体（agentic）时代。

## 📊 经济与科技政策

**联合国警告 AI 数据中心环境成本** — 报告指出，若忽视环境成本，AI 落地还将加剧土地紧张与电子废弃物问题，呼吁在 AI 发展同时重视可持续性。

**OpenAI 发布《智能时代的生物防御》行动计划** — 提出利用 AI 增强生物防御与韧性，构建 AI 驱动的生物安全能力以应对未来生物威胁。

**经济学家讨论 AGI 时代稀缺资源** — Alex Imas 和 Phil Trammell 指出，即使 AGI 实现，人类独特技能（如芭蕾舞演员）等稀缺资源仍不可替代。

## 📄 论文速递

**Google Research 发布被动心率监测系统 PHRM** — 利用智能手机前置摄像头在日常使用中捕捉面部视频，通过深度学习估算心率，MAPE 低于 10%，同时发布迄今最大规模的公开智能手机视频数据集。

**Nemotron 任务种子合成数据生成提高模型性能** — 在 Nemotron-3 Nano 的 100B token 续训练实验中，该方法使 MMLU-Pro 提升 1.8 分，GPQA 提升 11.1 分。

**NVIDIA PPISP：补偿光度变化提升 3D 重建鲁棒性** — 帮助补偿不同拍摄之间的光度变化，使 3D 重建在光照不一致时更加鲁棒。

今日 NVIDIA 以 Nemotron 系列密集攻势占据 AI 圈头条，多款模型覆盖安全评估、推理加速、语音识别等多个方向；neolab 的 Nex-N2-Pro 达到 GPT-5.5 级别并免费试用，大模型竞争进一步白热化。同时 Cloudflare 数据显示机器人流量首超人类，AI 对环境资源的消耗也在联合国报告中敲响警钟——技术加速带来的基础设施与治理挑战正在成为现实议题。
