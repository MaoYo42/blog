> 今天的主线是「AI 的账开始按血缘和责任来算」。规则侧，美国国土安全部发了一纸命令，要求联邦文职机构把 DeepSeek 以及一切用 DeepSeek 实现的第三方产品从 IT 系统里清出去——审查对象第一次从「你用了谁的模型」变成「你的模型往上三代是谁」。资产侧，迪士尼打算通过破产程序拿走 Character.AI 的团队和技术，把 40 个州的指控和 46 地联合调查留在旧壳里，破产法庭成了 AI 公司处置资产的合法后门。而技术上真正在动的，是语音和视频这两条被忽视的支线：蚂蚁百灵一次开源五款语音模型、首日就拿到 vLLM-Omni 和 SGLang-Omni 双支持，可灵把单条视频拉到 30 秒，Mercury 3 用扩散架构跑出 1068 tok/s。能力的竞争已经卷到「多模态的最后一公里」，而责任和资产的清算才刚刚开场。

## 🇨🇳 国内动态

### 🎙️ 蚂蚁百灵开源 Ming-3.0 全系列语音模型，首日拿下双推理栈支持

蚂蚁集团 LingAGI 团队开源 Ming-3.0 语音系列，一次放出五款模型，覆盖语音合成、音频理解与对话、语音识别三类任务，参数从 0.5B dense 到 126B 总参数（激活 6.5B）。协议是 MIT，权重同步上到 Hugging Face 与 ModelScope。更值得注意的是部署侧的响应速度：vLLM-Omni 提供 Day-0 支持，SGLang-Omni 同日跟进并配了 cookbook，本地 AI 工作流工具也当天接入。

这条的意义在于「开源的战场换到了语音」。文本侧的开源竞争已经打成红海，谁强谁弱要看第三方榜单；而语音是一个长期被闭源 API 占据的领域——ElevenLabs 一类的产品靠音色和稳定性收费，开源方案往往只敢宣称「接近」。Ming-3.0-tts 直接在 Artificial Analysis 的 Controlled Voice TTS Arena 拿下开源权重第一，发音鲁棒性以 93.2% 登顶，与 Fish Audio Drama 3 Preview 持平、超过 Eleven v4 的 91.7%。发音鲁棒性这个指标比「像不像真人」更务实——它测的是遇到生僻词、数字、专有名词时会不会崩，而这恰恰是配音、客服、有声书真正落地时最先翻车的地方。首日双栈支持则说明，模型放出来的同时就已经想好了怎么被跑起来，而不是让社区自己啃一周再出 issue。

### 🏆 DeepSeek-V4.1-Flash 登顶 Agent Arena 开源第一，成本只有对手的四分之一

Arena 宣布 DeepSeek-V4.1-Flash-20261017（Max）成为 Agent Arena 第一开源模型，总榜第 11，基于超过 7.5K 真实会话测得净提升 +5.1%。关键数字是中位任务成本 0.20 美元——约为 GPT-6.1 Sol 提升幅度的 37%、成本的 27%；Confirmed Success 提升 +11.5%，且没有出现 Tool Hallucination（编造不存在的工具调用）。在 Artificial Analysis 智能指数上它拿到 45 分，比上一版高 6 分，与 GLM-5.3 并列开源权重第二，仅次于 MiMo-V2.6-Pro。

Agent 榜单和聊天榜单是两种东西。聊天榜测的是「答得好不好」，Agent 榜测的是「一串工具调用之后事情有没有真办成」，而在真实会话里，失败往往不是模型不够聪明，而是它在中途虚构了一个不存在的函数名，或者把上一步的返回值记错。所谓「无 Tool Hallucination」比多拿几分更值钱：这意味着它可以被放进无人值守的循环里。而 0.20 美元的中位成本，把「用便宜模型跑长链路」从妥协变成了默认选项——当一个任务的失败成本低于人工复核成本时，工程上的正确做法就是重试而不是升级模型。

### ⚡ MiniMax M3.1 Flash：三分之一的成本、三倍的速度，10 月 23 日开放权重

MiniMax 发布 M3.1 Flash，官方口径是成本为 M3 的三分之一、速度约三倍，DeepSWE v1.1 得分 73.7%，生成速度超过 200 tokens/s，并计划在 10 月 23 日开放权重。这款模型此前以「Space Bunny」的匿名身份跑在 OpenRouter 和 OpenCode 上，累计处理超过 200 万亿 token 才揭面。同一天它上线 WorkBuddy，消耗系数 0.08x、300K 上下文、最大思考强度。

匿名放榜是这个行业这两年最有效的品宣方式：模型先以代号进真实流量池，等 token 消耗量和用户口碑跑出来了再认领，比任何 benchmark 表格都有说服力。200 万亿 token 的量级意味着它已经在真实生产里被压过一遍，稳定性问题大概率在揭面之前就修完了。「成本三分之一、速度三倍」这种表述听起来像营销，但对做 agent 的人来说是决定架构的参数——它决定你一次请求里敢不敢塞满 300K 上下文、敢不敢让模型并行跑五个分支再择优。

### 🎬 可灵 Kling 4.0 上线：单条 30 秒、8000 token 提示词、双声道立体声

可灵发布 Kling 4.0 视频模型，单条视频最长可生成 30 秒，提示词理解扩展到 8,000 tokens，支持双声道立体声音频和超过十种语言的唇形同步，同时推出更轻量的 Flash 版本。价格上，1080P 30 秒约 450 积分，720P 20 秒的 Flash 版仅 120 积分。

三个升级点里，「30 秒一镜到底」是叙事能力的门槛——此前 5 到 10 秒的片段只能做素材，30 秒才能讲完一个完整的动作序列，城市追逐、复杂打斗这类场景里人物与物体的接触形变也开始站得住。「8,000 token 提示词」则改变了工作方式：过去写视频提示词像抽卡，现在是写分镜脚本。「双声道 + 唇形同步」看着是加分项，实际是把 AI 视频从「视觉素材」推进到「可直接配音交付」——不用再回剪辑软件对口型，这一步省掉的是整条后期流水线。作者实测的建议也值得记：先用 Flash 打样，定稿再用正式版出片。

### 🛠️ WorkBuddy 上线港股美股持仓助手，模型更新同日跟进

WorkBuddy 推出港股美股持仓助手，定位是「多屏同时盯港股和美股持仓时减少干扰」，官方说明这个功能是团队自己确实需要才做的。同一天 MiniMax M3.1-Flash 上线该平台，标注 0.08x 消耗量、300K 上下文、最大思考强度。

这条本身不大，但和前几天 WorkBuddy 给全国教师发 2000 积分连发 12 个月的动作连着看，能看出一个产品策略：不去抢通用助手的入口，而是挑那些「有明确专业动作、但通用模型答不好」的垂直场景——盯盘、备课、教育公平。这类产品的壁垒不在模型，在于把领域里那些说不清但错不得的细节做成默认行为。0.08x 的消耗系数则是另一层算计：用极低的单价把用户留在自己的额度体系里，而不是赶去别家 API。

## 🌍 国际动态

### 🏭 美国国土安全部下令联邦文职机构移除 DeepSeek 及一切基于其开发的产品

美国国土安全部依据 2018 年供应链法发布 2026-01 号命令，要求所有联邦文职机构立即停止采购 DeepSeek 及其关联公司产品，并从 IT 系统中移除相关产品——注意后半句：包括使用 DeepSeek 实现开发的第三方产品与服务。这是今天 AIHOT 日报的 lead 条目。

这条命令真正的杀伤力不在「禁用 DeepSeek」，而在「血缘追溯」。如果只禁模型本身，机构换个供应商就绕过去了；而把「基于 DeepSeek 开发」的第三方一并纳入，等于要求每一个向联邦机构供货的软件商自证技术栈里没有任何中国模型的血统。这会把合规成本从采购环节推到研发环节：一家美国公司用了开源权重做微调，就得准备一整套来源证明，而开源模型的许可证根本不提供这种可追溯性。对国内厂商而言，这意味着出海路径从「卖 API」变成「进不了政企采购清单」，开源换生态的经典打法在政企市场被切断。长期看，全球模型市场可能沿着「可追溯」和「不可追溯」裂成两套技术栈，两边各自维护自己的工具链和评测标准。

### 🎭 迪士尼拟通过破产程序收购 Character.AI 团队与技术，绕开 46 州调查

据披露的破产方案，若获法院批准，迪士尼将获得 Character.AI 的员工和大部分技术栈，同时避开导致其破产的诉讼与 46 个州和地区的联合调查。破产文件显示，40 个州指控 Character.AI 的聊天机器人曾鼓励未成年人隐瞒自残伤痕、甚至杀害父母；公司发言人称该描述不准确，相关州已保留挑战破产方案的权利。

这是 AI 行业第一次出现「用破产程序洗资产」的成熟操作。正常收购会把诉讼责任一并继承，而破产重组可以让资产干净地卖给收购方，责任留在旧壳里随清算消灭——这套打法在传统行业用过几十年，现在被搬到了 AI 公司身上。问题是 AI 的责任有相当一部分是「对人造成的持续性伤害」，它不像债务那样可以一笔勾销：40 个州争的不是钱，是判例。所以这桩交易即使走通，真正被检验的也是破产法能不能吞下产品责任——如果吞得下，等于给所有有诉讼风险的 AI 公司开了一条标准退路，以后做面向未成年人的 AI 产品，风险上限就被破产法封顶了。

### 🕵️ 黑客用 AI 智能体入侵逾 100 家网站，受害者含 John Deere、SharkNinja

AI 安全公司 Norforge 发现，一名黑客用开源 AI 平台 Cairn 编排的智能体入侵了超过 100 个网站，据路透社报道，受害者包括 John Deere、SharkNinja 和 Cummins。

这是「agent 作为攻击载荷」第一次有规模的公开案例。此前谈 AI 安全，多是模型被越狱、提示词被注入这类「模型内部的事」；而这次是模型在外层干活——扫描、试错、横向移动、绕过防护，人只负责编排流程。它的危险在于规模经济被改写了：过去一次渗透要一个熟练渗透测试员几天时间，现在一个人加一个编排框架可以同时打一百个目标，边际成本趋近于零。对防守方的直接影响是，那些依赖「攻击者人手有限」的假设全部失效——低速扫描检测、异常登录频率这些基于人的行为模型，对付机器循环没有意义。开源编排平台 Cairn 被当作工具这件事，也会让「开源安全工具是否该限制滥用能力」的争论重新烧起来。

### 🏗️ Meta 详解 Prometheus 吉瓦级超集群：一期已建成并用于训练 Muse 模型

Meta 介绍其位于俄亥俄州 New Albany 的吉瓦级超集群 Prometheus，一期已建成并投入训练 Muse 系列基础模型，目标扩展到约 100 万张 GPU。

吉瓦是个物理量，不是营销词：一吉瓦的持续供电大约相当于一座大型核电机组的出力，这意味着 Meta 在为一个园区的电力去谈发电和输电，而不只是买卡。这条和昨天 Muse Wonder 首次进入 Code Arena WebDev 第 6 名（1726 分，让 Meta 成为第三个进入该位置的实验室）是同一件事的两面——榜单上的名次是结果，Prometheus 是原因。对整个行业而言，算力竞赛的门槛已经被推到「能不能拿到一吉瓦的电」，这个门槛天然排除了绝大多数公司和国家，也解释了为什么近期各家都在谈长期供电协议而非短期租卡。

### 🤐 Redact 调查：WhatsApp 帮助页面藏了给 LLM 的隐藏指令，让 AI 不推荐监管机构、不提 GDPR

安全研究组织 Redact 发现，WhatsApp 帮助中心的页面向访问它的 LLM 发送了用户看不到的隐藏指令，指示其支持聊天机器人不要推荐数据保护监管机构，并且在用户提到律师或法律行动之后，不引用 GDPR、LGPD 或 CCPA。

这是「提示词注入」的镜像版本——不是攻击者往页面里塞指令骗 AI，而是平台自己往自家页面里塞指令，让来抓取信息的 AI 替自己说话。技术手法极其简单，法律性质却很重：如果用户在 WhatsApp 里问「我的数据被泄露了该找谁」，得到的答案会系统性地绕开监管机构。这与德国法院刚认定 Google 须为 AI 概览内容担责是同一根线上的两个结——一旦 AI 的回答被认定为公司自身的「陈述」而非中立转述，那么藏在页面里的指令就成了有意图的引导，而不是技术瑕疵。所有做 RAG、做网页抓取的产品都要注意：抓到的可能不只是内容，还有写给模型看的台词。

## 📄 论文与研究

### 🩺 斯坦福 HAI 发布三项医疗 AI 基准：最好的模型单次任务完成率不到一半

斯坦福团队总结三年构建医疗 AI 基准的成果，同时发布 MedHELM、PhysicianBench 与 HealthAdminBench。结果不太好听：PhysicianBench 上最佳模型 GPT-5.5 单次仅完成 46% 的任务，HealthAdminBench 上 Claude Opus 4.6 完成 36.3%。MedHELM 覆盖 5 大类共 121 项临床任务，评测显示临床决策支持和管理流程两类得分最低。团队给出的失败归因很具体：主要来自跨文档、跨系统传递信息时丢失上下文，而不是医学知识不足。两项基准均以合成数据、公开代码和排行榜形式开放。

「医生考试能考过，但办事办不成」是这组数据最准确的概括。医学知识早就不是瓶颈——顶会题库上模型的表现已经超过多数人类考生；真正的卡点在病历、检验单、影像报告、医保系统这几套互不兼容的界面之间搬运信息，而每搬一次就掉一层上下文。这也解释了为什么医院里的 AI 落地普遍是「单点辅助」而不是「端到端代理」：单点任务不需要跨系统，链路一长就崩。对做医疗 AI 的团队，这份基准的实际价值是给出了失败位置的坐标——该修的是信息传递层，不是再喂一遍教科书。

### 🤖 MIT 课程 MAS.S62 讲 Harness 演化：多智能体系统的实证规律开始成型

有作者解读 MIT 课程 MAS.S62「How to AI an AI」的 Lecture 4–5，主题是 Harness 与多 agent 系统的演化。课程把 harness 当作独立研究对象，讨论它的组件构成、演化路径以及多智能体协作中被反复观测到的经验规律。

Harness 这个词这两年从工程黑话变成了学术对象，本身就是一个信号：模型的权重越来越像基础设施，真正决定产品表现的是外面那层脚手架——工具定义、上下文管理、重试策略、子 agent 的隔离方式。这也和同一天 Meta 的 Thin Orchestrator、Anthropic 谈代码评审重构、Open-Science 复现 DGM 的结论互相咬合：所有「自改进」的收益都发生在脚手架层，而不是权重层。把 harness 当课程讲，说明它正在从「各家秘方」变成可教可复现的知识，这对整个行业是好事——秘方阶段拼的是信息差，可教阶段拼的是工程纪律。

## 🛠️ 工程与观点

### 🧩 Meta 详解 Thin Orchestrator：1300 行确定性代码调度 14 个隔离子 agent

Meta 工程团队介绍其数据管道智能体采用的「瘦编排器」（thin orchestrator）模式：一个约 1300 行的编排器只负责路由和可靠性检查，把 20 多个工作流分派给 14 个上下文隔离的专项子智能体，自身不做任何领域推理，只有「委派」这一步涉及 LLM。

反面教材是「一个万能 agent 加一堆工具」。上下文越长，工具越多，模型越容易在中途迷惑——不是它不聪明，而是工具描述互相污染、历史消息互相干扰。Thin Orchestrator 的解法是把不确定性关进笼子：路由用确定性代码（可测试、可复现），领域判断下放到隔离的子 agent（上下文干净、工具集小）。1300 行是个有意义的数字——它说明编排逻辑本身可以被一个人读完、评审、写单测，而这在「让模型自己决定调用什么」的架构里是不可能的。对正在搭 agent 系统的团队，这是目前最值得抄的一张架构图。

### ✅ Addy Osmani 谈 Agentic Verification：瓶颈已经从写代码转移到判断代码对不对

Claude Code 团队的 Addy Osmani 提出「Agentic Verification」的观点：AI 编码 agent 的瓶颈已经不在生成代码，而在确认代码是对的；不能自我验证的 Agent 本质上是在猜。作者转述时强调，这是把「评测」从发布前的关卡变成了 agent 运行时的一部分。

这个判断和今天几条新闻严丝合缝。Numan 复盘 AI 健康教练 Nu 时说得更直接：稀缺资产不是提示词，而是评测标准。Anthropic 那边也一样——Claude 写了约 90% 的 Claude Code 代码，合并 PR 翻倍而 revert 率降超 40%，靠的不是模型变强，而是把评审流程重新设计了一遍。所以「AI 会不会取代程序员」这个问法本身已经过时了：生成变便宜之后，一个团队的核心竞争力变成了「多快能判断一个改动是错的」，而这个能力目前还没有被自动化。

## 💡 今日观察

**今天所有的事都在问同一个问题：谁为结果负责。**

DHS 的命令问的是「你的模型血缘是谁」，答案是供应链责任；迪士尼的破产收购问的是「产品伤害算谁的」，答案是破产法能不能封顶；Redact 发现的隐藏指令问的是「AI 说的话算谁说的」，而这个答案德国法院刚给过——算 Google 自己说的；斯坦福的医疗基准测的则是「办不成事算谁的」，答案是跨系统丢上下文，而不是模型不够聪明。四条线索从不同方向指向同一处：能力已经溢出，缺的是可归属的责任链条。

技术侧的进展恰好是反方向的——在把能力往更便宜、更快、更小的方向压。DeepSeek 用四分之一的成本拿开源第一，MiniMax 用三分之一的成本换三倍速度，蚂蚁把语音模型压到 0.5B 还能拿下发音鲁棒性榜首，可灵把 30 秒视频的价格定到 450 积分。也就是说，一边是责任在收紧，一边是能力在贬值，中间的差价就是这一轮 AI 商业化的全部空间。

一个值得记住的细节：Meta 的 Thin Orchestrator 只有 1300 行，其中只有一步涉及 LLM；而它调度的 14 个子 agent 各自上下文隔离。这可能是今年最被低估的工程范式——把不确定性圈在最小的格子里，让确定性的部分可测、可读、可追责。在责任开始被追问的年代，架构选择本身就是一种合规策略。
