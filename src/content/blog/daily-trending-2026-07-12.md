## 🚀 GitHub 热门项目

超快 JavaScript 运行时、打包器、测试运行器和包管理器一体机。

### 6. [hashicorp/terraform](https://github.com/hashicorp/terraform)
基础设施即代码的标杆工具。

### 7. [nasa/fprime](https://github.com/nasa/fprime)
NASA 开源飞行软件与嵌入式系统框架。

### 8. [zeux/meshoptimizer](https://github.com/zeux/meshoptimizer)
网格优化库，让 3D 模型更小、渲染更快。

### 9. [davila7/claude-code-templates](https://github.com/davila7/claude-code-templates)
Claude Code 模板配置与管理 CLI 工具。

### 10. [home-assistant/core](https://github.com/home-assistant/core)
