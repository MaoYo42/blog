## 🤖 AI 大模型动态

- **Fable 5 全球恢复上线，7 月 7 日起进入计费新阶段** — Anthropic 的 Fable 5 在经历 19 天政府出口管制禁令后终于恢复全球访问。新的安全分类器能 99% 以上阻止触发禁令的破解技术，但部分合法编码请求因模式匹配被误拦并回退至 Opus 4.8。Pro/Max/Team 用户可继续在 50% 周限额内免费使用至 7 月 7 日，此后 Fable 5 需信用额度计费，企业用户需按用量付费。

- **Kimi K2.7 Code 登陆 GitHub Copilot，成为首个可选开源权重模型** — Moonshot AI 的 K2.7 Code 开源权重模型正式在 GitHub Copilot 模型选择器中上线，由 GitHub 托管于 Microsoft Azure，按用量计费。逐步向 Copilot Pro、Pro+ 和 Max 计划推送，支持 VS Code、Visual Studio、JetBrains、Xcode、Eclipse 等主流 IDE。

- **Anthropic 与五角大楼爆发军事用途分歧** — 法庭文件显示，Anthropic CEO Dario Amodei 与五角大楼副部长数月邮件拉扯，焦点在于 Claude 的军事用途护栏。Anthropic 要求禁止全自主武器，五角大楼则希望用于所有合法国家安全场景。随后五角大楼将 Anthropic 列为供应链风险，部分合作方已切换至其他 AI 工具。

- **OpenAI 提议美国政府持股 5%，价值约 426 亿美元** — 据 Financial Times 和 CNBC 报道，OpenAI 提议向美国政府提供公司 5% 的股份，按近期 8520 亿美元估值计算价值约 426 亿美元。CEO Sam Altman 表示此举是与公众分享 AI 发展红利的最佳方式。

- **阿里巴巴发布 Page Agent：开源 JavaScript 库实现网页 DOM 自然语言操控** — 与 Playwright、Puppeteer 等外部工具不同，Page Agent 将实时 DOM 脱水压缩为文本映射，让纯文本模型精准执行点击、表单填写等操作。采用 MIT 许可，支持任意 OpenAI 兼容端点。

- **昆仑万维天工 3.2 发布 Skywork Tags，AI 智能体加入工作群聊** — 将 AI 以团队成员身份接入 Slack、飞书、钉钉、Discord、Telegram 等 IM 工具，团队可直接在群中 @Skywork 参与讨论。共享版 Agent 在吸收多样上下文后表现反超个人版。

- **Senior SWE-Bench 基准测试发布：最强 AI 在 75% 任务上不达标** — 评估 AI 完成高级软件工程师级别任务的能力。Claude Opus 4.8 搭配 Mini-SWE-Agent 以 24.0% 通过率居首，Claude Sonnet 5 为 19.4%，GPT-5.5 为 16.0%。每个功能任务平均涉及 11 个文件，最强智能体也需数百步完成。

- **阿里达摩院发布超导材料发现 AI 智能体 Elements Claw** — 联合中国人民大学、中国科学院大学发布，采用"专通融合"架构，基于 1.25 亿分子/晶体结构预训练的 1B 参数原子基础模型，判断超导性 AUC 达 0.996，预测临界温度平均误差小于 1K，仅用 28 个 GPU 小时完成筛选。

## 🔧 科技产品与行业

- **AI 版支付宝开放公测，蚂蚁阿宝无需邀请码即可体验** — iOS 和安卓用户可在应用商店或支付宝 App 搜索"阿宝"直接体验。右滑进入新版对话式界面，说出"查公积金"等指令即可自动匹配小程序和服务入口，资金变动均需用户本人确认。

- **微软成立 Frontier Company，斥资 25 亿美元派驻 6000 名 AI 工程师** — 新业务部门将 6000 名行业与工程专家派驻企业客户现场"共同设计、共同创新、部署并持续改进 AI 系统"。Microsoft 将自己定位为 OpenAI 和 Anthropic 的"平台中立"替代方案，联合埃森哲、凯捷、安永等系统集成商扩大覆盖。

- **花旗、Adobe 等企业限制员工使用 AI 旗舰模型控制成本** — 据 404 Media 获取的内部资料，多家企业月度 AI 开销飙升至 1500 万美元以上。花旗银行于 6 月 24 日禁用 Claude Opus 4.6/4.7 及 GPT-5.5 等旗舰模型，Adobe 于 6 月 30 日终止 Claude 无限制使用协议。Atlassian 财年 AI 支出预计超 1.2 亿美元。

- **快手可灵 AI 获 20.28 亿美元注资，投后估值 180 亿美元** — 21 名初始投资者以 138.24 亿元人民币现金注资，快手预计 12 个月内启动可灵 AI 赴港上市，募资用于扩充算力、建设数据中心及人才引进。

- **Claude Enterprise 新增用量分析与支出管控功能** — 仪表板可按群组和用户分析用量与成本，Claude Code 管理控制台新增"使用量"和"价值"选项卡，支持自然语言查询和可导出图表。管理员可设置模型默认权限并配置支出限额告警。

- **Google Health API 推出 CLI 工具 ghealth** — 开源的 Go 二进制命令行工具，封装 Google Health API v4，提供 40 种数据类型的结构化 JSON 输出，采用 Agent 优先设计，附带 SKILL.md 供 AI 智能体使用。

- **Runway 将闲置推理 GPU 回收用于研究** — 开发 deckard 容量控制器，在生产推理集群与研究集群间动态重分配 GPU。利用排队论确定目标利用率，避免 85% 利用率后的队列发散，使夜间闲置 GPU 回归研究。

## 📊 经济与科技政策

- **FTC 就 AI 准确性政策声明征求意见** — 美国联邦贸易委员会发布拟议政策声明，关注 AI 系统"压制准确性"问题，即 AI 公司可能因意识形态原因在特定话题上输出不准确结果。公众可在 7 月 31 日前提交评论。

- **OpenAI 提议美国政府持股 5%，估值 426 亿美元** — 这是迄今为止 AI 企业与政府之间最重大的资本绑定提议之一，引发关于 AI 治理与公共利益分配的广泛讨论。

- **谷歌 2025 年用电量增长 37%，AI 建设驱动创历史最大增幅** — 数据中心全年消耗超 4200 万兆瓦时，超过新西兰、丹麦等国家总用电量。自 2019 年以来谷歌总用电量已增长超 250%，AI 基础设施建设速度远超电网脱碳速度。

- **Menlo Ventures 募资 30 亿美元，创 50 年历史新高** — 得益于对 Anthropic 的早期押注，Menlo Ventures 完成其历史上最大规模募资，继续加码 AI 赛道。

- **Fable 5 在 RLI 基准中达 16.1% 自动化率** — Remote Labor Index 显示 Fable 5 完成专业质量自由职业项目的比例是八个月前最佳系统的六倍多，远超 Opus 4.8（8.3%）和 GPT-5.5（6.3%）。

## 📝 今日看点

Anthropic 的 Fable 5 在经历 19 天历史性政府禁令后恢复全球访问，成为今天最大焦点，同时也揭示了 AI 安全治理与商业可用性之间的深层张力。另一端，OpenAI 提出向美国政府出售 5% 股权的重磅方案，标志着 AI 企业与公共治理关系进入新阶段。从微软 25 亿美元组建 AI 驻场工程师部队，到花旗等企业因成本飙升限制旗舰模型使用，AI 行业正从"野蛮增长"转向"理性运营"的关键转折点。
