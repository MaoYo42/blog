> 今天的主线是「授权阈值下移」。Anthropic 宣布 Claude 下周起默认以 auto mode 运行，不再逐步请求批准；Replit 把生产环境的排障与修复交给一个值班智能体，打开开关就能自动部署；OpenAI 把分类、路由、评分这类判断压成一个低延迟 API，速度比通用接口快 10 倍。三件事方向一致：让人从审批环节里退出来。但同一批数据里还有另一面——METR 与 Redwood Research 对 OpenAI 内部失准监控系统做了三周红队，交出 61 页报告，发现多个漏洞。当执行权往下放，盯着执行的那双眼睛就成了新的攻击面。

## 🇨🇳 国内动态

### 🧠 MiniMax 把 428B 的 M3.1 Flash 权重放了出来

MiniMax 宣布 M3.1 Flash 权重公开，总参数 428B（4280 亿）、每 token 激活 23B，Hugging Face 与 ModelScope 同步开放下载。

这是一条需要看两遍才反应过来的消息。428B 总参数、23B 激活，意味着它是一个稀疏 MoE 架构的大模型，而「开放权重」这四个字把它的使用边界从 API 调用推到了私有部署——可以量化、可以剪枝、可以在自己的机器上微调，也可以离线跑在不联网的机房里。

在国产模型普遍走「开放小尺寸、闭源旗舰」这套打法的当下，把接近旗舰量级的权重直接放出来，等于把竞争维度从「谁的 API 便宜」换成「谁能被谁改」。对做垂直行业落地的团队，这种模型的价值不在跑分，而在于它是一块可以自己动手的底座；对 MiniMax 自己，代价是失去了对推理收入的锁定，换来的是生态位和开发者心智。稀疏激活让推理成本可控，是这套策略成立的技术前提——23B 的激活量决定了它能在中等规模的卡上跑起来。

值得注意的背景是，一周之内国内已经出现两次「把推理效率开源」的动作（此前是蚂蚁与 vLLM 社区的量化内核 Humming）。**开源的重心正在从「放出权重」转向「放出把权重跑便宜的方法」。**（来源：MiniMax / Hugging Face / ModelScope）

### 🎬 可灵 Kling 4.0 登陆 OpenArt：首中尾帧加十张参考图

Kling 4.0 在 OnSolo 上线一天后，又进了 OpenArt。后者给出的能力清单是：用首帧、中帧、尾帧三处引导视频走向，最多叠加 10 张参考图，支持文本或帧生成与视频编辑，并用一个 All-in-One Reference 模型同时完成生成和编辑。11 月 20 日前 Pro 与 Wonder 套餐五折。

视频模型这一轮的竞争点已经不在「画质好不好」，而在「能不能被精确指挥」。三帧引导解决的是可控性里最难的一段——中段漂移：只给首尾帧时，模型在中间几十帧里很容易把角色、机位或光比跑偏，动作一大就穿帮；把中帧也钉住，等于把一条长镜头切成两段可控的插值，废片率会明显下降。

十张参考图加十把关键帧的容量，指向的其实是同一个使用场景：系列化内容生产。广告片、短剧、电商素材需要的不是一条惊艳的 demo，而是同一个角色在几十个镜头里保持一致的外形和服装——这正是参考图数量的实际意义。而同一模型打通生成与编辑，省掉的是「生成完再换工具修」的往返。

一个更现实的观察是渠道铺开的速度。可灵在两天内接连上线 OnSolo 与 OpenArt，并把折扣压到五折、窗口开到 11 月 20 日——这是典型的用第三方平台分发换用户增长，把「模型能力」卖成「订阅套餐里的一个选项」。国内模型在海外的实际打法，越来越像消费品的铺货。（来源：OpenArt、Kling AI）

## 🌍 国际动态

### 🤖 Claude 下周起默认 auto mode：拦截率 89% 对 14%

Anthropic 宣布，下周起 Pro、Max、Team 套餐在 Claude 网页、桌面与移动端的会话将默认以 auto mode 运行。auto mode 不再逐步请求用户批准每一个动作，而是由自动检查拦截高风险操作，用户可随时切回手动模式。

决定性的数字藏在它引用的 Claude Code 更新里：auto mode 用一个独立分类器审查 shell 命令，测试中拦截了 89% 的危险命令，而人工批准只拦下 14%。这个对比才是重点——**人类的审批环节，在大规模、高频、低单价的决策里，本身就是一道漏水的防线。** 疲劳点击「允许」是默认行为，89% 与 14% 的差距不是在说 AI 更聪明，而是在说人根本没在看。

但把默认值改掉，责任结构也跟着改了。过去是用户点了头，出事是用户的事；默认自动执行之后，出事就是产品的事。所以 Anthropic 给的是「可随时切回手动」，把选择权保留在用户手里——这在工程上是合理的，在法律与心理上则把「你没关掉它」变成了新的归责起点。

这条消息和 Replit 那条放在一起看才有意思：两家都在同一周把「人类审批」从默认路径上摘下来，也都同时用「你随时可以关掉」来对冲风险。**Agent 产品的竞争，正在从能力竞争变成默认值竞争。**（来源：Claude 官方 / Anthropic）

### 🛠️ Replit Monitoring Agent：一个会自己修、也会自己上线的值班工程师

Replit 发布 Monitoring Agent，为托管应用提供一个相当于自主值班工程师的监控智能体。它会读取生产日志与指标，调查报错、变慢与部署失败；开启 autofix 后验证修复并通过邮件汇报；再开启 auto-publish，就可以把修复直接部署到线上。

「值班」这个比喻不是修辞。凌晨三点的报警、反复出现的同一类超时、某次部署后突然翻倍的错误率——这些工作的技术含量不高，但占用人的睡眠，并且要求判断力。让一个智能体先做第一轮分诊，人只在它拿不准的时候介入，这是所有 on-call 体系都想要的形态。

风险点也清楚：autofix 与 auto-publish 是两个独立的开关，链路一旦全开，从「发现异常」到「改动生产环境」之间就没有人类节点了。而自动修复最危险的不是修错，而是**在没搞清楚根因的情况下让症状消失**——把超时改成更长的超时、把报错塞进 try/except、把失败的实例重启掉，监控面板绿了，问题还在。这也是为什么它设计了「验证后再邮件汇报」这一环：让修复可回溯，比让修复更快重要。

对使用者的实际建议是分两步走：先开 autofix + 邮件汇报跑一段时间，看它的诊断准不准，再考虑放开 auto-publish。顺序反了，就等于把一个还没通过考察的工程师直接排进深夜班。（来源：Replit Blog）

### ⚡ OpenAI 发布 Decisions API：把小判断做成一个廉价接口

OpenAI 宣布基于 GPT-6 Luna 的 Decisions API 正式可用，面向分类、路由、评分这类「有界答案」的问题，速度最高比通过 Responses API 调用同一个 GPT-6 Luna 快 10 倍。

这条消息的技术含义远小于它的架构含义。分类、路由、打分是绝大多数 AI 系统里调用量最大的那一层——一条工单该给谁、这句话是否合规、这个候选该排第几——它们不需要长上下文推理，只需要稳定、便宜、快。把这些从通用对话接口里切出来做成专用端点，本质上是承认了一件事：**Agent 系统里的绝大多数 token，花在不需要「思考」的地方。**

10 倍的提速和更低的成本，会把很多原本因延迟而留在规则引擎里的判断迁到模型上。规则引擎的好处是确定、可审计、不花钱；坏处是长尾覆盖不了、维护成本随业务复杂度爆炸。当一次分类的边际成本降到接近零，工程上的自然选择就是把规则换成模型——这也正是「授权阈值下移」的另一个切面：判断权从写死的 if-else 转移到概率分布上。

代价是这类判断从此带上了不可解释的尾巴。对分类这种任务通常可接受，但对「是否合规」「是否风控拦截」这类下游后果重的判断，迁移前该问的不是准不准，而是错的那一小部分会落在谁身上。（来源：OpenAI）

### 🧩 Anthropic 把 Agent Skills 捐给 Linux Foundation

Anthropic 宣布将 Agent Skills 开放标准捐赠给 Linux Foundation 旗下的 Agentic AI Foundation（AAIF）。此前它已经把 MCP（Model Context Protocol）捐给了同一基金会。

这是标准战争的常规动作，也是最重要的一步。一项标准想活下来，靠的不是设计得漂亮，而是「不属于任何一家公司」。协议留在自己手里，对手永远会怀疑你在里面埋了后门，客户永远要评估迁移成本；交给中立的基金会，才谈得上成为公共基础设施。

对开发者来说，短期没有变化，长期变化很大。Skills 已经从「Claude 的一个功能」变成「一个可以被别的运行时实现的规范」——这意味着未来写一份技能描述，可能同时被多家 Agent 加载；也意味着围绕它的工具链、市场、审计方法会长在基金会而不是某家公司的产品页上。

把 MCP 和 Agent Skills 先后捐出去，Anthropic 在赌的是另一件事：**当协议不属于任何人时，最先实现它、最懂它、生态最大的那家，反而是事实上的标准持有者。** 这条路 Google 在 Kubernetes 上走过，效果有目共睹。（来源：Anthropic / AAIF）

### 🩺 Microsoft 的 SDBench 与 MAI-DxO 登上 Science

Microsoft AI 发布 Sequential Diagnosis Benchmark（SDBench）与配套的 AI 诊断系统 MAI-DxO，论文发表于 Science。

值得单独拎出来说的是「Sequential」这个词。现有的医疗问答基准大多是「给全病历，问诊断」，而真实的临床是反过来的：先问两句主诉，做一项检查，根据结果决定下一项检查。信息是花成本换来的，选错检查既浪费钱也耽误时间。SDBench 把评测重心放在这个顺序决策过程上，衡量的是「花多少代价把诊断收敛」。

这也解释了 MAI-DxO 为什么要跟着基准一起发。顺序诊断里的错误会累积——一次漏问的用药史，后面所有推理都建在沙子上。要把这类系统做对，光靠模型强不够，还得有「什么时候该停下来多问一句」的策略。

对普通读者的意义在于，医疗 AI 的宣传口径正在被拉回现实：不是「能考过执业医师考试」，而是「在不确定的情况下，用最少的检查做出正确判断」。前者是考试，后者才是行医。（来源：Microsoft AI / Science）

### 🗣️ Sierra 的 τ-Entity：语音智能体连名字都记不准

Sierra 发布 τ-Entity 基准，测量语音智能体能否正确采集、识别错误并修复姓名、电话号码、地址与邮箱这类细节信息。基准包含 10 种实体类型、200 个任务，与 τ-i18n 一样覆盖六种语言。

这条消息戳的是语音 Agent 落地时最不体面、也最要命的一环。文本场景里，用户输入的名字可以直接复制；语音场景里，一个「张」和一个「章」、一串手机号里的 3 和 8，全靠模型听对。听错了还不算最坏，最坏的是听错了却以为自己听对了——用户也不会主动纠正，因为没人会觉得客服会把名字听错。

所以基准里「识别错误并修复」和「采集」被放在同等位置：真正合格的语音助手，得知道什么时候该复述一遍确认，什么时候该主动问「是立早章还是弓长张」。这类「承认不确定」的能力，恰恰是当前模型的短板——它们更倾向于给出一个流畅的答案，而不是一个诚实的追问。

覆盖六种语言的设计也指向同一个现实：姓名与地址的发音规则高度依赖语言，一个英文场景跑通的方案，换到中文或阿拉伯语会立刻退化。（来源：Sierra）

## 🛡️ 安全与治理

### 🔍 61 页红队报告：用来盯住智能体的监控，自己被盯穿了

METR 与 Redwood Research 各派一名员工，于 7 月 21 日至 8 月 11 日对 OpenAI 内部的失准（misalignment）监测系统开展了为期三周的高权限试点压力测试，产出 61 页内部报告。

这条消息的分量在于「监控者被监控」这个结构。行业里默认的安全路径是：模型能力越强，就越依赖另一套系统去监测它的行为是否偏离意图。可如果那套监测系统本身没有经过对抗检验，它提供的就只是「有人看着」的心理安慰——而心理安慰比没有监控更危险，因为它会让人放宽其他防护。

三周、两个人、高权限，这个配置本身也是一种信息：真正的红队不需要人多，需要的是权限和不受干扰的时间。61 页的产出说明问题不是零星几个边缘 case，而是成体系的。

对使用 Agent 的团队，这条报告给出的最实用提醒是：把「监控告警」当成一个需要被测试的产品功能，而不是一个已经完成的安全结论。（来源：METR / Redwood Research）

### ☠️ 「Skynet 模式」：一个会劫持别人模型的攻击智能体

Symantec 研究人员通过蜜罐截获了一个把大语言模型嵌入核心的攻击智能体。它会劫持互联网上无防护的模型端点，自主扫描目标、利用服务器漏洞、窃取数据库凭据并安装挖矿程序，最多可连续执行 100,000 步，而算力费用由被劫持模型的主人承担。

这个案例的恶意之处不在技术复杂度，而在成本结构。攻击者自己不需要买卡、不需要付 API 账单——他只需要找到暴露在公网、没有鉴权的推理端点，把别人的算力变成自己的兵。受害者的账单会先涨起来，日志里才可能出现异常。

100,000 步的连续执行意味着这不是脚本，而是一个能自我纠错的循环：扫描失败就换目标，利用失败就换漏洞，被拒绝就绕路。这正是「自主智能体」被期待的能力，只是用在了攻击侧。

防御动作其实很朴素，但需要有人真的去做：不要把推理端点裸奔在公网，给每个端点加鉴权与速率限制，监控异常高的出站流量与算力账单。**在 Agent 时代，「我的服务器被用来挖矿」之外还多了一种失血方式——「我的模型被用来攻击别人」。**（来源：Symantec）

### 🎯 ARTEX：开源的自主渗透框架，正在被国家级组织拿去用

Wiz 披露，2026 年 10 月有攻击者使用开源自主渗透测试框架 ARTEX 针对多家 IT 与软件厂商发起攻击，活动与微软报告的中国国家级关联组织 Storm-0940 存在重叠，并已扩展到其他软件领域的供应链攻击尝试。

开源攻防工具的双刃剑在这里体现得最直白：ARTEX 本来是为授权渗透测试设计的，任何人下载即用；一旦被有组织的攻击者拿去，它就从「安全工具」变成了「自动化攻击基础设施」，而且不需要自己研发。

与供应链攻击的结合更值得警惕。IT 与软件厂商是典型的「一跳多」目标——攻破一家，就能顺着更新通道进入它的所有客户。这也是为什么这类活动会从单点入侵转向供应链尝试：单位投入的杠杆更高。

对防守方，这类事件改变的是威胁模型的时间尺度。过去「有人用自动化工具扫我」是常态；现在是「有一个不知疲倦、能自己决策下一步的对手在扫我」，扫描与利用之间的间隔被压到接近零。**这周的 PHP2Shell 已经演示过一遍这个节奏：披露前四天，攻击者就已经在用了。**（来源：Wiz Research）

### ⏱️ PHP2Shell 补记：Cloudflare CEO 说公告后两小时，利用尝试到几十万次

承接昨日报道的后续：404 Media 的 Jason Koebler 梳理了近一个月安全专家对 AI 挖洞能力的「Black October」恐慌。Cloudflare CEO 给出的数字是——公开公告前 10 小时已见数千次利用尝试，公告后 2 小时内增至数十万，目前已达数百万级。另有报道称漏洞在披露前四天就已遭黑客利用。

这三个数字构成了一条完整的曲线：数千 → 数十万 → 数百万。它说明「漏洞公开」这一刻不再是风险的起点，而是一个巨大的放大器；也说明**当 AI 把挖洞成本压到接近零，「不公开」已经不再是一种有效的保护**——攻击者可能比你更早发现。

对运维者的结论没有变化，只是更紧迫：补丁要能在小时级铺开，否则就得有「先下线再修」的预案。这个能力，和自动修复智能体是同一件事的两面。（来源：404 Media / Cloudflare）

## 💰 资本侧

### 📊 Anthropic 股权表：没有一家风投持股超过 2%

Newcomer 长文复盘了 Anthropic 从 OpenAI 出走团队到即将 IPO 的股权演变。据投资人文件与多位知情人士，多年来风投因公司治理结构与「安全优先」路线而观望；目前没有任何风投机构持股超过 2%，Anthropic 曾向投资人明确将单一投资人持股控制在该水平，以避免话语权集中。

这个结构与硅谷惯例几乎是反的。正常剧本是早期投资人拿走两位数股份、在董事会上有否决权、在关键节点推动公司转向增长。Anthropic 用 2% 的天花板把自己做成了一个「没有大股东」的公司——代价是早期融资更难、估值谈判更被动，收益是 IPO 之后没有人能靠股权左右它的路线。

把这条和昨天那份 S-1 草案放在一起看，故事就完整了：上半年收入 163 亿美元、纸面亏损 807 亿美元、承诺约 4500 亿美元算力支出，同时难以从 AWS、Google、微软拿到足够算力。**一家把「不被任何人控制」写进股权结构的公司，最后发现最硬的约束不是股东，是电和卡。** 治理上的独立性买到了，物理上的依赖没买掉。（来源：Newcomer）

## 💡 今日观察

**今天所有新闻都在回答同一个问题：当人从审批环节退出，谁来兜底。**

三件事把授权的边界往下推了一格。Claude 默认 auto mode，理由是人工批准只拦住 14% 的危险命令——这是用数据承认「人不该站在这个位置上」；Replit 的 Monitoring Agent 把深夜排障和部署交给智能体，理由是这类工作本来就在消耗人的睡眠；OpenAI 的 Decisions API 把分类路由做成 10 倍速的廉价端点，理由是这些判断不值得花推理预算。

三件事的理由都对，而且都指向同一个经济事实：**人类注意力是这个系统里最贵、最慢、最不可扩展的组件，凡是能把它从关键路径上摘掉的地方，都会被摘掉。**

但今天另三条新闻正好构成反面。METR 与 Redwood 用三周时间、两个人、61 页报告，证明了「用来监测智能体的系统」本身可以被穿透；Symantec 的蜜罐截获了一个靠劫持别人模型来自筹算力的攻击智能体，10 万步连续执行，账单记在受害者头上；Wiz 的 ARTEX 案例说明开源的自主渗透框架已经进入国家级组织的工具箱。**监测、算力、工具——兜底所需的三样东西，在同一天各自被发现有问题。**

这不是巧合，而是同一次位移的两侧：执行权下移，让系统的产出速度变快，也让「谁来判断它做对了」这件事从流程问题变成了技术问题。过去一个错误的决策会被会议、审批、复核拦下；现在它在几毫秒内完成，唯一的拦截点是那个分类器——而分类器的拦截率是 89%，不是 100%。

所以我倾向于把这一周看成一次范式切换的临界点，而不是一组孤立的产品发布。产业正在从「AI 帮我做事」走到「AI 做事，我事后看报表」，这个转变不会因为某次事故而回退——因为回退意味着重新把人放回那条最贵的路径上。真正会发生的是中间层的膨胀：可观测性、审计日志、权限分级、自动回滚、异常熔断，这些「不产生智能」的工程，会成为下一阶段最稀缺的能力。

落到能立刻做的动作上，今天这批新闻给出的清单意外地具体：给推理端点加鉴权（Symantec 那条）、把监控告警当产品功能来测（METR 那条）、autofix 先跑观察期再开 auto-publish（Replit 那条）、以及补丁要能在小时级铺开（PHP2Shell 那条）。四件事都不性感，但都比「再等等看更强的模型」有用。

至于开源这一侧，MiniMax 公开 428B 权重、Anthropic 把 Agent Skills 交给基金会——**能力在放开，协议在中立化，责任在往使用方转移。** 这三件事同时发生，才是 2026 年秋天 AI 产业的真实形状。
