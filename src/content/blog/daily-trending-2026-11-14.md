今天榜单的关键词是**「给 Agent 装护栏」**：榜首不是模型，而是代码审查、安全扫描、规范对齐这类工程侧工程。以下数据取自 GitHub Trending 当日页面（星数为页面展示值）与 V2EX 热门话题接口。

### 🚀 GitHub 热门项目

1. **GoogleChrome/modern-web-guidance-src**（TypeScript，5,054 ★，今日 +1,925）
   Google 官方仓库，用途是让编码 Agent 随时跟上最新的 Web 最佳实践。今日增量断层第一，说明「让 Agent 写对现代前端」已成刚需。

2. **openai/codex-security**（TypeScript，13,248 ★，今日 +751）
   OpenAI 的 Codex Security CLI 与 TypeScript SDK，用于发现、验证并修复安全漏洞，npm 上可直接装。

3. **we-promise/sure**（Ruby，14,874 ★，今日 +925）
   面向所有人的个人财务应用，口号是 "by everyone"——开源、自托管，可自己掌握账本数据。

4. **alibaba/open-code-review**（Go，50,811 ★，今日 +215）
   阿里开源的代码审查工具，混合架构：确定性流水线 + LLM Agent，支持行级精确评论，内置多语言规则集（空指针、线程安全、XSS、SQL 注入），兼容 OpenAI 与 Anthropic 接口。

5. **ZhuLinsen/daily_stock_analysis**（Python，71,841 ★，今日 +256）
   LLM 驱动的多市场股票智能分析系统：多源行情、实时新闻、决策看板与自动推送，主打零成本定时运行。中文项目里最完整的一套「自建投研流水线」。

6. **backnotprop/plannotator**（TypeScript，10,556 ★，今日 +108）
   给 Agent 加「人在回路」的工作台：勾勒、决策、规划、标注、审代码、共享给团队，反馈一键回传给 Agent。

7. **block/buzz**（Rust，37,351 ★，今日 +97）
   Block（Square 母公司）的「蜂群思维」通信平台，Rust 实现。

8. **louislam/uptime-kuma**（JavaScript，93,950 ★，今日 +71）
   老牌自托管监控工具，仍在榜，说明自建监控的需求从未退潮。

> 读榜小结：前六里有四个在做「让 Agent 的输出可被审查、可被约束」——代码审查、安全扫描、规划确认、规范同步。能力增量让位于工程可控性。
