## 🤖 AI 大模型动态

**MiniMax 开源 M3 模型权重及 MSA 技术论文**
MiniMax 开源了 428B 总参数、23B 激活参数的 M3 模型权重，同步发布 MSA（MiniMax Sparse Attention）技术论文。M3 是首个从预训练阶段就进行文本、图像等多模态交错混合训练的开源模型。发布两周后，M3 在 Artificial Analysis 综合智能指数等多个排行榜中均获开源模型第一。

**DLash 投机解码与 Spec V2 引擎发布**
Z Lab、Modal 与 SGLang 团队联合发布 DFlash 投机解码模型和 SGLang 的默认 Spec V2 引擎。通过块扩散+KV 注入并行技术，在 Qwen 3.5 397B 模型上实现 4.3 倍吞吐量提升，大幅降低推理延迟。

**Kimi K2.7 Code 高速版上线**
月之暗面推出 Kimi K2.7 Code 高速版，输出速度约 5-6 倍于普通版，常规编程场景达 180 Token/s，短上下文可达 260 Token/s。同期推出为期三周充值优惠活动。

**Anthropic Fable 5 / Mythos 5 遭美国政府限制访问**
美国商务部以出口管制为由，要求 Anthropic 暂停所有外国用户对 Fable 5 和 Mythos 5 模型的访问。Anthropic 被迫全球禁用这两款刚刚发布的最强模型，引发业界对 AI 模型出口管制的广泛讨论。

## 🔧 科技产品与行业

**Salesforce 以 36 亿美元收购 AI 客服平台 Fin**
Salesforce 宣布以 36 亿美元收购 AI 客服平台 Fin（前身为 Intercom）。Fin 提供跨实时聊天、WhatsApp、短信、电话等多渠道的 AI 智能客服，可自主解决 76% 的客户问题，年收入已达 1 亿美元且以 350% 的速度增长。交易将增强 Salesforce 的 Agentforce 平台。

**Meta 在 Facebook 上线"AI Mode"搜索功能**
Meta 在 Facebook 推出"AI Mode"，利用 Meta AI 从公开帖子、群组和 Reels 中提取信息并合成答案，用户可用自然语言提问获得摘要。同时新增视频拼贴、AI 照片预设等功能。Meta 近期还启动了全球订阅计划（每月 3.99 美元起）。

**Nvidia 发行 200 亿美元债券**
Nvidia 计划通过自 2021 年以来的首次债券发行筹集至少 200 亿美元，加入 AI 领域的债务融资热潮，为数据中心和芯片产能扩张提供资金。

**xAI 推出 Grok Build Agent Dashboard**
xAI 为 Grok Build 推出 Agent Dashboard，提供单一屏幕管理多个编码会话。支持按状态分组、实时查看输出、分派新任务等。同时，Grok 已集成至 Warp 终端开发环境，服务近百万开发者。

**GitHub 发布多语言开发者开源数据集**
GitHub 在 CC0-1.0 许可下发布仓库级多语言数据集，涵盖 README、issue 和 pull request 等开发者内容，以推动多语言 AI 研究与开发。

**Claude Code v2.1.178 发布**
更新新增工具参数匹配语法、嵌套技能自动加载、改进子 agent 评估等功能，修复了多平台崩溃问题。

**TIOBE 6 月榜单：Rust 创新高，Python 下滑**
TIOBE 编程语言指数 6 月数据显示，Rust 升至第 12 位，创历史新高，成为关键基础设施领域的标准选择。Python 跌破 19%，C++ 超越 Java 重回第三。

## 📊 经济与科技政策

**国产 GPU 四小龙燧原科技科创板 IPO 过会**
上海燧原科技科创板 IPO 申请获上市委审议通过，拟融资 60 亿元。至此，"国产 GPU 四小龙"（摩尔线程、沐曦股份、壁仞科技、燧原科技）将齐聚资本市场。燧原科技与腾讯深度绑定，腾讯既是股东又是大客户。

**美国伊朗达成和平协议**
据 21 世纪经济报道，美伊已达成和平协议，国际地缘政治格局出现重大变化，有望缓解全球能源市场的不确定性。

**中国新一代通信网加速构建**
6 月 15 日，我国在东风商业航天创新试验区使用力箭一号运载火箭成功发射卫星，推进"从地面到太空"的数字底座建设。

**AI 裁员浪潮持续发酵**
今年科技公司已累计裁员约 15 万人，日均 974 人，速度比去年快 44%。AI 已连续三个月被列为裁员首要原因。与此同时，AI 芯片商 Cerebras 上市首日市值达 670 亿美元。

## 📝 今日看点

AI 产业进入了"大交易+强监管"的新阶段：Salesforce 以 36 亿美元收购 Fin 凸显 AI 客服的商业价值，Nvidia 发行 200 亿美元债券表明行业仍在疯狂扩张；而 Anthropic Fable 5 遭美国政府限制则预示着地缘政治博弈已深入 AI 模型层面，开源模型和本地部署的重要性随之上升。国内方面，国产 GPU 四小龙齐聚资本市场，算力自主化迈出关键一步。
