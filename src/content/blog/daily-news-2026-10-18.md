> 今天没有发布会级别的大模型，但有一条更值得琢磨的线：DeepSeek 在同一天把「模型」和「搜索」两件事同时往前推了一格，且都没有涨价。模型侧是 V4.1-Flash-1017 的静默升级，搜索侧是自研引擎的 API 化——后者意味着检索这一层正在从「调用别人的索引」变成「自己拥有索引」。与之呼应的是硬件和工程两端的变化：37999 元的 RTX Spark 笔记本被几分钟抢空，说明「本地跑得起」已经从极客玩具变成了有支付意愿的商品；而 Claude 写下自家产品约 90% 代码且回退率下降 40% 的数字，则把「AI 写代码」从演示拉进了可审计的工程指标。能力、成本、信任，今天这三条线罕见地同向移动。

## 🧠 模型发布

**DeepSeek-V4.1-Flash-1017 静默上线：价格不动、调用名不动、只动成绩** — DeepSeek 把 V4.1 Flash 升级到 DeepSeek-V4.1-Flash-1017，网页端与 App 同步更新。最值得注意的是它「什么都没改」的部分：API 调用方式与价格保持不变，仍然用 `deepseek-flash` 这个模型名访问。对已经上线的业务来说，这是一次零迁移成本的换引擎——不需要改配置、不需要重算预算、不需要重新做 A/B 分流，只要不锁死版本号就会自动吃到新权重。这种发布策略本身就是一种产品判断：在 Flash 这个价位段，用户要的不是「可以选的新模型」，而是「一直在变好的同一个模型」。代价是版本追溯变难，做评测的团队最好自己记录调用日期，否则跨月对比会失真。（来源：[DeepSeek API 更新日志](https://api-docs.deepseek.com/zh-cn/updates/#deepseek-v41-flash-1017-更新)）

**WorkBuddy 第一时间跟进，免费窗口开到 10 月 31 日** — 海外版 WorkBuddy 宣布已更新至 DeepSeek-V4.1-Flash-1017，10 月 31 日前免费开放，并针对 DeepSeek Harness、腾讯 CodeBuddy、WorkBuddy 等自家工具链做了适配优化。这条新闻单独看很小，但它是观察国产模型生态扩散速度的一个采样点：从模型侧更新到下游工具跟进，间隔已经压到小时级。更实际的信息是那句「输出更短」——对按 token 计费的开发者来说，输出长度下降等于账单下降，这类优化比跑分提升更能直接影响留存。（来源：[WorkBuddy](https://x.com/WorkBuddy_AI/status/2111404103402430558)）

## 🛠️ 产品与硬件

**DeepSeek 开放自研搜索 API：检索层开始被模型厂商自己吃掉** — DeepSeek 正式开放自研搜索 API，底层是 AI 原生的搜索引擎，官方称每天稳定处理数亿次搜索请求，索引覆盖全球千亿级网页、支持多语言，并通过识别机制过滤 SEO 作弊、GEO 操纵和低质 AIGC 内容。这条的分量在架构层面：过去做 RAG 或智能体，检索几乎默认外包给第三方搜索 API，模型厂商只负责「读」；现在模型厂商开始同时提供「找」和「读」，检索质量、延迟、成本可以被端到端优化，但整条链路的可替换性也随之下降。官方特别点出反 GEO 操纵（生成式引擎优化），说明「给 AI 看的 SEO」已经成为一门生意，也已经是需要对抗的对象。（来源：[DeepSeek API 更新日志](https://api-docs.deepseek.com/zh-cn/updates/#开放自研搜索-api)）

**华硕 ProArt 创16 实测：37999 元、128G 统一内存，几分钟售罄** — 卡兹克分享了受邀参加英伟达 RTX Spark 全球开售活动后、深度使用一周华硕 ProArt 创16 的体验，配置为 RTX Spark N1X 芯片 + 128G 统一内存 + 1T 存储，京东售价 37999 元，开售时 128G 版本几分钟内被抢空。这台机器的意义不在参数，而在它给出了「本地 Token 自由」的第一个明确标价：把 128G 统一内存塞进笔记本，等于让 800 亿级甚至更大的 MoE 模型在本地常驻，不再按 token 付费、不再把私有数据送出去。抢空说明有一批人算过这笔账——当云端 API 的月度支出、数据合规成本和延迟不确定性叠加到某个阈值，一次性买断硬件反而更划算。这是消费级硬件第一次真正参与大模型的经济学讨论。（来源：[X @Khazix0918](https://x.com/Khazix0918/status/2111639562720329976)、[微信公众号](https://mp.weixin.qq.com/s?__biz=MzIyMzA5NjEyMA%3D%3D&mid=2647687354&idx=1&sn=dea0d54dc3b71b361e36199db6cf4a86)）

## 💡 工程与观点

**Claude 写下约 90% 的 Claude Code 代码：PR 翻倍、回退率反降 40%** — Anthropic 公开了 Claude Code 代码评审体系的重构思路：机器承担大部分阅读工作，人类的注意力集中到高风险决策上。配套的数字比方法论更有说服力——2026 年 6 月到 9 月，合并 PR 数量翻倍以上，而 revert 率下降超过 40%；monorepo 的每日变更量从 5 月的约 2500 次涨到 9 月的超过 30000 次。把这三组数字放在一起看，结论是反直觉的：代码产出量级跳了一个数量级，质量指标却同步改善。这说明瓶颈从来不是「写」，而是「评审带宽」——当评审被重新设计成机器先行、人类兜底的结构，产量和质量可以同时上升。反过来说，任何只加 AI 生成、不改评审流程的团队，大概率只会得到更多待审代码和更长的队列。（来源：[X @shao__meng](https://x.com/shao__meng/status/2111274173192638932)、[claude.dev](https://claude.dev/blog/solving-code-review-at-anthropic/)）

**Meta 用 human-on-the-loop 八周做完 Forum：AI 原生工程的可复制样本** — Meta 工程团队详解了如何把 AI 智能体当作开发流程的参与者来构建独立的 Groups 应用 Forum，采用 human-on-the-loop（人在环上）而非 human-in-the-loop，成功标准是「验证通过的生产级产出」。结果是八周内达到与 Facebook Groups 核心功能对齐，自主压测循环在开发期发现并修复了内存问题，内存占用与缺页约减半；上线后智能体还参与用户反馈的根因分析。这个案例值得抄的不是工具选型，而是组织形态：人不再逐行把关，而是设定验证标准、盯着异常。它的隐含前提是测试覆盖足够好——没有可靠的自动验证，「人在环上」就等于「人不在环上」。（来源：[Meta Engineering](https://engineering.fb.com/2026/10/15/ml-applications/how-meta-built-forum-ai-native-engineering/)）

## 🏭 行业与治理

**Anthropic Q3 营收 168 亿美元，增速从 140% 掉到 45%，IPO 估值预期下修** — Anthropic 在面向潜在投资者的会议上公布 Q3 营收 168 亿美元，环比增长约 45%，明显低于 Q2 超过 140% 的增速；年内调整后营业利润率为 11%，现金流为正，每 1 美元算力支出产生 1.70 美元收入。部分投资者对数字失望，路透社称 IPO 估值预期从此前讨论的约 2 万亿美元下调至约 1.5 万亿美元。这里有个容易被忽略的细节：增速放缓发生在毛利率转正的同时。也就是说，Anthropic 正在从「烧钱换增长」切换到「有利润地增长」，而资本市场给出的反馈是估值打折——高增长叙事和盈利叙事在同一家公司身上并不总能叠加。对一级市场的启示是，AI 公司的估值锚点正在从收入增速移向单位算力的回报率。（来源：[The Decoder](https://the-decoder.com/anthropics-q3-revenue-hits-16-8b-but-growth-slows-ahead-of-planned-november-ipo/)、[IT之家](https://www.ithome.com/1/013/723.htm)）

**a16z：智能体购物被电商大规模拦截，403 响应自夏季起翻倍** — a16z 图表周报指出，Cloudflare 数据显示智能体与爬虫收到的 403 拒绝响应自夏季起明显增多，约为原先的两倍。文章同时给出需求侧数据：42% 的消费者完全不信任 AI 代购，NRF 数据显示退货率与退货成本自 2019 年以来分别翻倍和增至三倍，Similarweb 显示 AI 购物多发生在「发现」与「购买」之间的中间环节，而非下单环节。这条与「智能体接管一切」的叙事正好相反：供给侧在关门，需求侧不信任，中间的退货成本还在涨。真正卡住智能体商务的不是模型能力，而是责任归属——谁为下错的单负责，这个问题没有答案之前，403 只会越来越多。（来源：[a16z](https://www.a16z.news/p/this-week-in-charts-agents-denied)）

**Eiliko 机器人玩具 6.8 万台设备数据裸奔，3.1 万份儿童档案暴露** — The Verge 记者与黑客 Sammy Azdoufal 实测发现，Energize Lab 的 Eiliko 机器人玩具把用户对话、用户画像、儿童照片和音频存放在无防护的服务器上，可访问约 68000 台设备、1300 万条对话，其中超过 31000 份儿童档案来自美国。这类事件在「AI 硬件」浪潮里会反复出现，原因很朴素：玩具厂商擅长做交互和外观，不擅长做后端权限；而大模型让玩具第一次开始长期存储孩子的语音和对话，风险敞口从「一次性录音」变成了「持续画像」。监管的落点大概率不在模型，而在联网儿童设备的数据最小化要求上。（来源：[The Verge](https://www.theverge.com/tech/1010727/eiliko-robot-hack-energize-lab)）

## 📄 研究速递

**开放权重模型的间接提示词注入易感率高 88%：26.7% vs 14.2%** — PromptArmor 在 9800 次试验的评测中发现，开放权重模型（DeepSeek、Kimi、GLM、Qwen）对真实世界间接提示词注入攻击链的易感率为 26.7%，闭源模型（GPT、Claude、Gemini）为 14.2%，开放权重模型易感率高出 88%。这个差距的来源值得推敲：闭源模型除了权重更强，还多了一层厂商侧的安全后训练与输入过滤，而开放权重的部署方往往直接用原始权重对外服务。换句话说，「易感」有一部分不是模型的属性，而是部署方式的属性。对自建模型的企业来说，这条数据等于提示：权重拿到手只是开始，安全对齐和输入侧防护需要自己补齐。（来源：[PromptArmor](https://www.promptarmor.com/resources/open-weight-susceptibility)）

**Claude Mythos 5 闭环优化量子电路，八项任务全超已发表最优** — Anthropic 发布研究报告，让 Claude Mythos 5 在闭环中自主优化量子电路：模型提出电路设计，自动评估器验证正确性并按 qubit 数乘以门数打分，八项涵盖化学、优化、量子模拟和数论的任务均超过此前最优已发表设计，部分提升达一个数量级以上。这是「AI 做科学」里比较干净的一种范式——目标函数明确、验证自动化、结果可复现，不需要人类评委打分。它同时也划出了边界：能被形式化验证的领域，AI 的收益最确定；而验证本身需要人类共识的领域，进展会慢得多。（来源：[Anthropic](https://www.anthropic.com/research/designing-efficient-quantum-circuits)）
