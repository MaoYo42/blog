## 🚀 GitHub 热门项目

今日 GitHub Trending 涌现了一批 AI Agent 相关的优秀项目：

- **[apple/container](https://github.com/apple/container)** — Apple 开源重磅工具，用于在 Mac 上创建和运行 Linux 容器（轻量级虚拟机），用 Swift 编写，专为 Apple Silicon 优化。兼容 OCI 镜像标准，可直接拉取 Docker Hub 等仓库镜像。

- **[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills)** — Google Chrome 团队 Addy Osmani 出品的 AI 编码 Agent 技能集合，封装了资深工程师的工程实践、质量门禁和最佳实践 workflow。

- **[NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector)** — NVIDIA 开源的 AI Agent 技能安全扫描器，研究显示 26.1% 的 Agent 技能存在漏洞、5.2% 包含恶意意图，这款工具帮你回答"这个技能安全吗？"

- **[LMCache/LMCache](https://github.com/LMCache/LMCache)** — 为 LLM 推理加速的 KV 缓存管理层，将 KV 缓存从临时状态转变为可复用的 AI 原生知识，减少首 Token 延迟、提升吞吐量。

- **[kenn-io/agentsview](https://github.com/kenn-io/agentsview)** — 本地优先的 AI 编码 Agent 会话分析与洞察工具，支持 Claude Code、Codex 等 20+ 种 Agent，号称比 ccusage 快 100 倍。

- **[microsoft/PowerToys](https://github.com/microsoft/PowerToys)** — 微软 Windows 系统增强工具集，常年霸榜的开源实用工具合集。

- **[andrewyng/aisuite](https://github.com/andrewyng/aisuite)** — Andrew Ng 出品的 AI 套件，简化多模型调用。

- **[swc-project/swc](https://github.com/swc-project/swc)** — 用 Rust 编写的超快速 JavaScript/TypeScript 编译器，比 Babel 快 20 倍以上。
