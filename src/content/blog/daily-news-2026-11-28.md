这三天最集中的一条线不是模型，而是**账**——信任的账、算力的账、叙事的账。

一边是信任在变贵：安全公司 Dragos 称 MiniMax 在用户明确要求「不要存储」的情况下，仍然打开并访问了用户提示词里的私有链接；42 州总检察长正在法庭上阻止一场拍卖 2100 万美国用户聊天记录的破产清算。另一边是算力在变便宜：Anthropic 把 Messages API 从 Python 迁到 Rust，每请求 CPU 降约 70%，同期流量的 1800 倍增长没让它停服一天；Mantic 与 Thinking Machines 用后训练把预测智能体的单次成本砍到 1/15。

两条曲线交叉的地方，就是接下来一年产品竞争的真实战场：**模型能力不再是瓶颈，能不能被信任、跑不跑得起，才是**。

## 🌍 国际动态

**🔓 Dragos 指控 MiniMax 无视「不要存储」仍打开私有链接**
美国安全公司 Dragos 发布调查称，MiniMax 收集并打开了用户提示词中的私有链接，即便用户明确要求不存储数据。这条新闻的分量不在技术，而在**信任模型**：绝大多数用户对 AI 产品的隐私预期是「我说不存就不存」，但提示词里的链接一旦被服务端展开抓取，就等于把内网地址、带 token 的临时 URL、甚至别人分享的私有文档暴露给了一次你没批准的请求。这与同周的 Character.AI 破产拍卖案形成呼应——42 州总检察长正在阻止一场涉 2100 万美国账户（其中 210 万为未成年人）的聊天记录拍卖，唯一披露的竞拍方是 11 月 13 日才在特拉华州注册的 Smirks and Pangs Acquisition LLC。**当对话数据成为可交易资产，「不存储」这四个字就必须变成可审计的技术承诺，而不是一句产品说明。**

**🎙️ Anthropic 复盘 API 从 Python 迁到 Rust：CPU 降 70%，零停服**
Anthropic 介绍了 Messages API 从 Python 迁移到 Rust 的做法，核心方法很值得记：**把生产系统本身当作校验器**——新旧实现并行跑，用真实流量做差分验证，而不是先写一套测试再迁移。结果是每请求 CPU 降低约 70%，首 token 中位时间缩短约 20%，期间该 API 流量从 2024 年初到 2026 年秋增长约 1800 倍，且没有停服、没有冻结功能开发。1800 倍这个数字说明一件事：**推理服务的成本结构里，语言运行时和内存管理的权重被长期低估了**。对做 Agent 产品的团队而言，这是一份可以直接抄的迁移方法论。

**📉 Mantic 与 Thinking Machines：预测智能体成本降 15 倍**
Mantic 与 Thinking Machines 在 Tinker 上对 Inkling 2 Small 做后训练，得到一个端到端完成研究与预测的智能体，准确度接近 Fable 5.2（medium）档，但单次预测成本降低 15 倍。这条的价值在于**方向**：不是把更大的模型塞进流水线，而是用小模型 + 后训练 + 端到端任务定义，把「研究—取证—预测」这一整条链压进一次调用。同样的思路正在多个团队重复出现，它意味着「深度研究类 Agent」的商业模型第一次可能算得过账。

**🧩 Pydantic AI 发布终端编码 Agent Pax：一切皆插件**
Pydantic AI 发布基于 Harness SDK 的终端编码 agent Pax（pydantic-ai-pax），设计哲学是「一切皆插件」：`--agent` 可接入自定义 Pydantic AI Agent，`/sandbox` 可在十余种云端或本地沙箱间切换，支持 ComputerUse 计算机使用，并默认开启 code mode。同时宣布 Harness 将在约一个月后进入 1.0。**编码 Agent 的竞争已经从「谁的模型强」转到「谁能换模型、换沙箱、换工具而不改架构」**——可替换性本身成了产品力。

**🖥️ OpenClaw 2026.11.10：Deep Research、Knowledge 记忆与 Browser handoff**
OpenClaw 发布 2026.11.10 版本，新增聊天内 Deep Research、新的记忆系统 Knowledge，以及 Browser handoff（把浏览器会话交接给用户或另一个执行体）。这个版本累计 7,671 个 PR、349 位贡献者，版本说明见 docs.openclaw.ai。三个功能指向同一个缺口：**长任务的连续性**——研究要有中间态、记忆要跨会话、人机交接要有明确的责任边界。

## 🇨🇳 国内动态

**🔊 上海 AI 实验室 InternLM 发布全双工语音视频模型 Sage-Interaction**
上海人工智能实验室 InternLM 团队发布开源全双工语音视频模型 Sage-Interaction，基于 MiniCPM-o 4.5 构建。面壁智能 OpenBMB 转发点评称其能「边说边听」，并在不打断对话的前提下把复杂任务交给后端模型处理。**全双工是语音交互的分水岭**：过去的语音助手是「你说完我再说」的轮次制，全双工意味着模型必须同时处理听、说、判断何时插话三件事，工程难度远高于把 ASR、LLM、TTS 串起来。开源这套能力，对做陪伴、客服、硬件语音入口的团队是直接可用的基座。

**🖼️ 蚂蚁 inclusionAI 开源 Ming-Image-0.2-Design**
蚂蚁 inclusionAI 在 Hugging Face 发布并开源 Ming-Image-0.2-Design，重点改进复杂构图、光照和文字渲染，官方定位在电商主图、UI 设计稿与空间效果图。**文字渲染是图像模型长期的老大难**，而电商主图恰恰是最吃「图上文字不能错」的场景——把一个垂直场景做到可用，比在通用榜单上多几分更有商业意义。

**💰 支付宝 SkillPay 实测：把 Skill 挂上去卖钱的完整路径**
作者完整实测了支付宝 SkillPay 的 Skill 变现流程。平台 7 月上线，支持买断与订阅两种模式：买断制把 Skill 完整内容交付到本地，定价 0.01–50 元；订阅制把 Skill 留在云端沙盒，Agent 看不到明文，按周／月／季度收费、上限 50 元，免费试用最低 5 次。**这是「Agent 技能」第一次有明确的交易结构和知识产权保护设计**——订阅制不让 Agent 看到明文这一条，本质上是为提示词资产设计了 DRM。对独立开发者来说，通道存在本身就是信号。

## 📄 观点与风险

**🗣️ Dario Amodei 澄清：从未主张向 AI 交出人类自由意志**
Anthropic 的 Dario Amodei 发长文否认其主张「向 AI 交出人类自由意志」，称其一贯立场是 AI 必须受合法民主程序治理。他区分了两个层面：全球治理层面的交权，与具体任务的自动化，后者他持混合态度——包括对递归自我改进设限、警惕端到端部署带来的就业冲击。他还提到 Anthropic 曾拒绝让自家模型用于自主武器，并在文末批评部分 AI CEO 只喊「人类控制」口号而无实质行动。Elon Musk 转发并评论「Interesting」。**这场澄清本身说明，AI 治理的争论已经从「要不要管」进入「谁在管、管到哪一层」的技术细节阶段。**

**⚠️ Ed Zitron：黄仁勋回归是符号操作，流动性风险一个没解决**
Ed Zitron 撰文分析 NVIDIA 董事会恢复黄仁勋 CEO 职位一事，认为这是应对外部压力的符号性操作，并未解决行业面临的循环融资、流动性紧张以及 OpenAI 亏损等根本问题。文章梳理了 NVIDIA 对 AI 行业的巨额资金支持、Anthropic 上市后的股价表现（本周一度跌破 83 美元发行价、盘中最低约 76 美元、较首日高点回撤约 34%）与 OpenAI 的财务压力作为证据。**读这类文章要有分辨力**：作者的结论偏悲观，但他列的资金链条是可核查的事实——当芯片厂商的营收、云厂商的资本开支、模型公司的融资三者互为客户，任何一环的估值重估都会传导到另外两环。
