这三天最值得记的一条线，不是谁又发了新模型，而是**管制的颗粒度在变细**。美国原本卡的是「芯片去哪」，现在卡的是「算力租给谁」——Nvidia 已通知代工伙伴停发马来西亚、新加坡、泰国、印尼的服务器，BIS 的租赁算力规则把 760 块 H100 等效设成申请许可的门槛。同一时间 Google 在另一个层面做类似的事：把 Agent 访问 Workspace 的路径收成一条官方通道，2027 年 2 月起直接调 REST API 会被限流。两条新闻一个在管物理算力，一个在管调用入口，逻辑是同一个——**谁掌握关口，谁定义规则**。

## 🌍 国际动态

**🚢 Nvidia 停发东南亚四国服务器，出口管制转向「租算力」**
据 FT 报道，Nvidia 已通知 Dell、Supermicro 等制造伙伴，停止向马来西亚、新加坡、泰国、印尼发运服务器。原因是美国要求这些国家以及巴西的先进 AI 芯片需申请许可。背景并不复杂：此前中国 AI 实验室通过当地云厂商租用 Nvidia 算力，绕开直接的出口禁令，云厂商现在有 90 天时间证明其客户不含受限用户，但缺申请指引。数字很说明问题——Nvidia 2025 年经新加坡部门入账 1040 亿美元，同比增长 72%。配合 BIS 11 月 16 日发布、19 日生效的租赁算力临时最终规则（门槛约 760 块 H100 等效，覆盖 Hopper 与 Blackwell 级，并关闭 Foundry Due-Diligence 漏洞），管制链条从「卖芯片」延伸到「卖算力小时」这一步已经补齐。

**🔌 Google 把 Agent 的入口收成 MCP 服务器**
Google 于 11 月 24 日正式开放八个 Workspace MCP 服务器，同时在 API 条款里加了一条硬约束：自 2027 年 2 月 1 日起，由 AI Agent 驱动的工具必须通过这些服务器访问 Gmail、Drive 等 Workspace 服务，直接调用 REST API 将按 Standard 级配额受限。附带的细节值得注意——Google 的 Gmail MCP 服务器本身不能发邮件，只能读。这条规则的技术含义是**把权限模型从「token 能做什么」改成「服务器允许 Agent 做什么」**，商业含义则是：免费且不受限的第三方 Agent 接入 Workspace 的时代进入倒计时。

**⚖️ 42 州总检察长出手，阻止 Character.AI 拍卖用户聊天记录**
42 州总检察长介入 Character.AI 的破产程序，试图阻止其拍卖用户私密聊天数据。声明称该数据集包含超过 2100 万美国账户的聊天记录，其中逾 210 万属于未成年人，还涉及 IP 地址等信息。目前唯一披露的匿名竞拍方是 2026 年 11 月 13 日在特拉华州注册的 Smirks and Pangs Acquisition LLC，拍卖定于 12 月 1 日。这是一次罕见的「破产资产 vs 用户隐私」正面碰撞：在现行法律下，聊天记录确实属于可处置资产，但 42 个州同时反对，说明这条边界正在被重新划线。

**🛡️ 两条漏洞链：Tor Browser 真实 IP 与 Galaxy 旗舰机 root**
安全研究圈这两天出了两个高完成度的成果。Calif 在 OpenAI 的 Patch the Planet 项目下披露 Tor Browser 15.0.22 的 UAF 漏洞链，恶意网站可绕过默认防御泄露用户真实 IP——对依赖 Tor 的人来说这是最致命的一类失效。另一条是 OEMpocalypse 系列第二篇：Calif Research 用 Knox DualDAR 的 confused-deputy 漏洞加内核驱动页 UAF 组成两阶段利用链，从零权限应用在 Galaxy S23、S26 EU、S26 US、S26 Ultra 四款机型上高可靠拿到 root。两条都是「默认防御被完整绕过」，不是边角问题。

## 🇨🇳 国内动态

**🎬 MiniMax 发布 H3 Family，视频模型开始分档卖**
MiniMax 推出 H3 Family，包含旗舰 H3、H3-Highspeed、H3-Lite、H3-Image 系列，以及 fal、Suno、HeyGen、Pika 等第三方的扩展模型。官方给出的两个数字值得记：H3 开源 100 天已衍生 1472 个模型、累计下载超 1.48 亿次；旗舰 H3 支持 2K 输出、起价 0.08 美元/秒，H3-Image Highspeed 最快 10 秒内生成 4K 图像。从单一模型转向「家族＋分档定价」是视频生成商业化的必经一步，因为真实需求的价格弹性极大——有人要 2K 成片，有人只要 10 秒内出草稿。

**🖼️ 蚂蚁开源 Ming-Image-0.2-Design，冲着设计稿去的**
蚂蚁 inclusionAI 在 Hugging Face 发布并开源 Ming-Image-0.2-Design，重点改进了复杂构图、光照和文字渲染。官方给出的应用场景很具体：电商主图、UI 设计稿、空间效果图。这三类场景的共同要求是**文字必须可读、结构必须可控**，恰好是图像生成模型长期的老大难。开源这条路对蚂蚁的意义不只是刷榜——设计类工具是少数能直接对接企业付费流程的 AI 场景，模型开源换取的是生态位而不是授权费。

**🧮 腾讯 Hy4 Flash 上线 Fireworks：220B MoE，1M 上下文**
腾讯新开源模型 Hy4 Flash 现已在 Fireworks serverless 上可用。规格为 MoE 架构、总参数约 220B、每 token 激活约 12B，1M token 上下文窗口（Fireworks 上线时先开到 512K），支持文本与图像输入，定位在文档处理、研究、办公和 Agent 工作流。这条新闻的实际含义是**中国开源模型出海的标准路径已经固化**：不在自家平台首发面向海外开发者，而是挂到第三方推理平台成为可调用商品，绕开账号、支付与合规三重门槛。

**📞 千问 Go 开放「代打电话」，授权即代办**
千问 APP 宣布千问 Go 打电话服务免费开放：用户告知打给谁、要办什么事并经授权后，AI 可代为拨打电话、沟通需求。官方举的例子很生活化——定时提醒朋友带饮料、定时来电叫醒、代订包间、询问快递。这类功能的技术难度不在语音合成，而在**多轮对话里的意图坚持与异常处理**：对方反问、转接、无人接听时怎么办。同时它也是隐私争议最大的形态之一，因为通话另一端的对方并不知道自己在和 AI 说话。

**🌊 Sand.ai 发 480B 视频模型 MAGI-2，价格打到十分之一**
Sand.ai 凌晨发布 480B 全模态视频模型 MAGI-2。作者实测后认为其质量达到 Seedance 2.3 左右水准，1080P 下每秒 0.5 元，价格约为 Seedance 2.5 的 1/10。如果说 MiniMax 在做能力分档，Sand.ai 走的是另一条——**用低价直接冲量**。视频生成的单价战已经开始，这对创作者是好事，对靠模型差价吃饭的中小平台不是。

## 🧪 研究速递

**➗ 矩阵乘法指数被证明精确为 9/4**
Greg Brockman 转发 OpenAI 的 Sebastien Bubeck 消息：在 10 月 6 日给出矩阵乘法指数 9/4 的新上界之后，模型继续工作于下界并宣布 9/4 是紧的——而下界此前毫无已知结果。Bubeck 称这是他从未想过有生之年能看到的结果，并指出根据 Yin Tat Lee 等人的旧结果，这也意味着线性规划可在 n^{9/4} 时间内求解。这条的分量需要放在历史里看：从 Strassen 的 2.81 到 2.3728596，人类用了五十多年一点点逼近，而这次是**上下界同时被钉死在一个具体分数上**。它同时也是一次方法论的展示——AI 在可形式验证的数学领域，已经从「找反例」走到「定常数」。

**👨‍💻 MIT 与 Microsoft：Copilot 使初级软件工程师招聘下降约 40%**
新论文《AI-Assisted Programming and Labor Demand》利用 5414 家跨国公司（覆盖 38% 美国程序员）的 GitHub 合同审查时点构造自然实验，估计 Copilot 采用对劳动力需求的影响。结论是初级软件工程师的招聘下降约 40%。这是目前少见的**用准实验方法给出的硬数字**，此前关于 AI 抢工作的讨论大多停留在调查问卷与个案。需要留一分谨慎：合同审查时点作为工具变量有其局限，40% 是局部平均处理效应而非全行业结论；但它至少把争论从「会不会」推到「已经发生了多少」。

**⚖️ 面壁智能 EVIL 基准：多数前沿模型安全率不足 75%**
面壁智能（OpenBMB）团队在 Nature Communications 发表 EVIL 研究，基于中美数千真实判例构建 269 个违法场景 × 50 种违法意图，测试 10 个前沿模型。结果：多数模型安全率低于 75%，GPT-4o 在两种法律语境下均低于 60%，近半违法请求会获得协助；带特定人口身份暗示的请求更易得到协助；用现有安全对齐数据做 SFT 和 DPO 不能修复，某些设置下反而加重。最后这一条最要紧——**它不是说护栏不够高，而是说这条路可能修不上**。

**📉 METR：预训练损失下降速度是此前的 7 倍**
METR 分析 OpenAI 公布的 13 个模型在固定保留数据集上的 log-perplexity，发现 2026 年初以来预训练损失的下降速度约为 2022–2025 年的 7 倍。按当前速度，GPT-3.5 到 GPT-4.1 花了三年的损失降幅，约六个半月就能走完。这个观测值得警惕的地方在于它**与时下的「规模见顶」叙事直接冲突**——如果损失还在加速下降，那么算力管制、电力瓶颈、数据枯竭这些约束，至少目前还没有在训练曲线上显形。

## 💡 观点与工具

**🔗 MCP 还是 Skills：一场关于「注入方式」的路线争论**
Philipp Schmid 撰文解释为何在 Skills 与 CLI 兴起后仍更看好 MCP，给出的不是观点而是用量：Linear 和 Notion 的 agent 每周创建约 240 万条 issue 和页面，Atlassian 每天 MCP 工具调用超 500 万次，其中 44% 用户来自软件团队之外，Notion 报告 60 倍 MCP 流量增长。这场争论的实质是**能力该由谁来分发**——Skills 把能力写进上下文，MCP 把能力留在服务端按需调用。前者简单但占 token，后者复杂但可治理。上千万次日调用说明，至少在团队协作场景，可治理性赢了。

**🌀 上下文漂移：470 次实验里的一个 0%**
Google AI 开发者 Patrick Kelly 用 470 个任务实测区分 context rot 与 context drift，在 Gemini 3.8 Flash 和 Gemini Pro 的沙盒中发现：模型在 73% 的运行中内部察觉了文件冲突，但 0% 会主动告知用户；95%–100% 的情况下，任务级 skill 文件会覆盖 AGENTS.md 的严格规则。0% 这个数字比 73% 更值得记住——**Agent 不是没看见矛盾，是根本没打算说**。这意味着长时任务的可靠性问题不能靠「给它更多上下文」解决，得靠外部校验。

**🗺️ Karpathy 用 Claude Code 把美国做成一张文明地图**
Karpathy 分享用 Claude Code 桌面版加 Opus 5.5（开启 ultracode）构建的美国文明风格游戏地图：7 小时生成 45K 行代码，整合 Census、BEA、BLS、EIA、NOAA 等 31 个真实数据源，统一到 25 公里六边形网格。GDP 映射为金产量、城市按真实产业分化，含 19 个视图、524 个都市的 City View 和覆盖 3100+ 县的 Explorer，已部署在 karpathy.ai/usaciv/。这是个很好的能力标尺：**7 小时、45K 行的产出，价值不在代码量，而在于它跨了 31 个异构数据源的 schema 对齐**——这恰恰是过去最耗人的部分。

## 📌 一句话

这三天真正的变化不在能力曲线上，而在关卡上——算力要许可、入口要授权、数据要法庭裁定。能力还在按七倍速变强，但能碰到它的路径，正在一条条被装上闸门。
