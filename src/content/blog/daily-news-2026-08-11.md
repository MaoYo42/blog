## 🇨🇳 国内 AI 动态

**🏠 阿里千问开放平台上线：租房、寄快递、查理财都能「对话办理」** — 8 月 10 日千问开放平台正式上线，面向生态伙伴和开发者开放手机、PC 和 AI 眼镜三类终端的服务接入，首批覆盖物流运输、房产居住、本地生活、理财、汽车等十多个领域，顺丰速运、自如租房、哈啰租车、闪送、盈米基金、联想乐享等已接入。用户在千问对话中 @ 相关服务或点击「圆点角标」即可进入智能体，完成从咨询、推荐到下单履约的完整链路；平台提供账号、AI 支付、订单接入等基础设施，第三方 Agent 可通过标准化协议一键授权、端到端调测快速迁移上线。**为什么重要**：这是国产大模型「超级入口」之争的关键落子——千问不再只是聊天工具，而是变成「对话即服务」的应用分发平台，把高频生活服务全部装进同一个对话窗口，顺丰智能体甚至能记住寄件地址直接完成「帮我把文件寄给上海客户」。**影响**：智能体从「能聊天」走向「能办事」，传统 App 的下载-打开-操作流程可能被对话取代；对中小服务商而言，接入开放平台是低成本获得流量、支付与账号体系的捷径，超级 App 的 AI 化改造正在全面提速。 [来源](https://www.ithome.com/0/987/720.htm)

**👀 通义千问开源 Qwen-MM-Plugins：让智能体原生支持多模态** — 阿里开源 Qwen-MM-Plugins，让智能体原生具备读取图片、视频、文档，以及编辑视频、处理 3D/CAD 等能力，实现从「多模态模型」到「多模态智能体」的跨越。**为什么重要**：当前智能体大多只能「读文字」，而真实办公场景里大量信息藏在图片、视频、CAD 文件里——多模态工具插件是智能体从「对话助手」升级为「数字员工」的必经之路。**影响**：与千问开放平台形成组合拳，开发者可以用一套开源工具链让 Agent 看懂并操作真实世界内容，国产智能体生态的工具标准正在成型。 [来源](https://github.com/QwenLM/Qwen-MM-Plugins)

**⚙️ 智谱 ZCode 四大功能上线：GLM-5.2 编码任务通过率反超 Claude Code 组合** — ZCode 针对 GLM 深度优化，今日上线 Goal、Subagents、Remote Control 与闲时任务四大功能；在 Z.ai Code Bench 测试中，GLM-5.2 搭配 ZCode 比搭配 Claude Code 的任务整体通过率高 2.39%，缓存命中率超 98%，叠加 1.5 倍限时额度加成后整体使用量接近常规额度的 1.8 倍。**为什么重要**：编码智能体的竞争已从「模型单挑」进入「模型 + 工具链」整体对决——谁能把 Agent 框架与模型协同调优到极致，谁就能在开发者市场拿到真实份额。**影响**：国产编码工具链的性价比优势（高缓存命中率 + 额度加成）正在打动价格敏感的中小团队，Claude Code 在国内开发者中的替代选项越来越多。 [来源](https://aihot.virxact.com/daily/2026-08-11)

**💬 微信内测「AI 帮写」与「AI 点评」：朋友圈的 AI 含量要爆表了** — 微信基于小微推出朋友圈 AI 帮写与 AI 点评内测：前者可根据图片和已写文字生成 3 条朋友圈文案，后者可长按文字生成评价或快捷评论；公众号端小微还常驻首位，自动总结常看公众号文章。**为什么重要**：这是 AI 首次直接嵌入中国最核心的社交场景——朋友圈的内容生产与互动都可能被 AI 接管，「社交货币」的生成方式正在被改写。**影响**：一方面降低了表达门槛，另一方面也引发「朋友圈最后一点人味消失」的担忧；国民级社交产品把 AI 放在产品中心而非边缘，标志着 AI 渗透社交关系的临界点到来。 [来源](https://aihot.virxact.com/daily/2026-08-11)

### 🔥 头条

**🌐 Meta 回归开源：发布 30B 智能体模型 Muse Glimmer，单张消费级显卡可跑** — Meta 发布开放权重模型 Muse Glimmer：300 亿参数（含约 18 亿视觉编码器），Apache 2.0 协议，专为本地、常驻运行的智能体工作流优化，量化后小于 20GB，可在 24-32GB 显存的 Mac 或高性能 PC 上运行，上下文 128K+；SGLang 已与 Meta Superintelligence Labs 合作提供 Day-0 推理支持。扎克伯格同步发布长文《超级智能应人人可用》，并预告 Muse Spark 1.2 的权重也即将开源。**为什么重要**：Muse 系列此前被视为 Meta 转向闭源的信号，如今带着「30B 本地智能体」回到开源——这一次的赌注不是「跑分」，而是「智能体能否离开云端、跑在每个人的设备上」，扎克伯格在长文里把「超级智能人人可用」上升为 Meta 的价值观宣言。**影响**：本地智能体市场被点燃：30B 量级 + Apache 2.0 + 消费级硬件，意味着个人开发者可以私有化部署常驻 Agent、数据不出设备；对重度依赖云端 API 的智能体生态是一个方向性信号，端侧芯片与个人电脑厂商也将从中受益。 [来源](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model) · [纽约时报中文网](https://cn.nytimes.com/technology/20260811/meta-ai-open-source/)

**🏗️ 英伟达联手六大机构：动员超 5000 亿美元第三方资本建「AI 工厂」** — 英伟达宣布与 Apollo、BlackRock、Blackstone、Brookfield、Goldman Sachs 和 KKR 签署谅解备忘录，建立独立的算力融资平台，为超大规模云厂商、前沿 AI 实验室和企业建设数据中心、采购英伟达硬件动员超 5000 亿美元第三方资本，把「英伟达算力」变成可借贷、可证券化的基础设施资产类别。黄仁勋称「在 AI 里，算力就是收入」，BlackRock CEO Larry Fink 称这是把长期资本与关键基础设施连接起来。**为什么重要**：AI 算力的融资模式正在发生范式转移——以前是科技公司自己掏钱买 GPU，现在是华尔街把它当成「像电厂、收费公路一样的基础设施」来投资，英伟达芯片第一次成为可以抵押融资的资产类别。**影响**：5000 亿美元级别的长期资本入场将显著缓解 AI 建设的资金瓶颈，但也把「AI 是否过度投资」的赌注绑上了华尔街的资产负债表；对国内厂商而言，海外算力军备竞赛的资本厚度再上一个台阶。 [来源](https://www.cnbc.com/2026/08/10/nvidia-wall-street-asset-managers-500-billion-ai-push.html) · [NVIDIA](https://nvidianews.nvidia.com/news/nvidia-partners-with-apollo-blackrock-blackstone-brookfield-goldman-sachs-and-kkr-to-establish-ai-compute-infrastructure-financing-platforms-to-mobilize-over-500-billion-of-third-party-capital)

**🛡️ OpenAI 发布 GPT-5.6-Cyber：网络安全专用模型，通过 Daybreak Red 提供给授权研究人员** — OpenAI 扩大网络安全计划 Daybreak，发布 GPT-5.6-Cyber：基于 GPT-5.6 Sol 训练，针对零日漏洞发现、exploit 链开发等专业任务优化，并减少对高风险双用途网络任务的拒答；通过 Daybreak Red 提供给授权的漏洞研究、漏洞验证与安全测试人员，官方称已在真实漏洞研究中发现 Chrome v8 引擎等流行开源软件的未知漏洞。**为什么重要**：这是前沿实验室首次把「专用于攻击性安全研究」的模型做成正式产品线——在安全防御窗口不断收窄的背景下，OpenAI 选择「给好人发武器」而不是「让所有人赤手空拳」，也与其此前披露的智能体攻破 Hugging Face 事件形成呼应。**影响**：安全研究社区的能力上限将被抬升，但「授权」边界的界定与滥用风险也随之而来；预计 Anthropic、Google 会跟进推出同类专业模型，AI 网络安全赛道的军备竞赛正式开打。 [来源](https://openai.com/index/expanding-daybreak-as-the-cyber-defense-window-narrows/)

### 🛠️ 产品与发布

**🧭 OpenRouter 推出新版 Auto 路由器：用每周 55T token 的市场数据选模型** — OpenRouter 发布由市场智慧驱动的新版 Auto 路由器（openrouter/auto）：基于社区每周超 55T token 的真实消费数据，按约 30 种任务类型匹配近 7 天实际被使用的模型，支持 cost_tier 成本档位并遵循账户隐私设置；在 MMLU Pro 等基准上，新默认档位在多数领域以更低成本达到旧版同等性能。**为什么重要**：当模型数量爆炸，「该调用哪个模型」成了开发者最头疼的问题——OpenRouter 把全网真实消费行为变成路由信号，让「抄作业」式选模型成为可能。**影响**：模型路由将从「规则配置」进化到「市场驱动」，价格与质量的动态博弈被自动化；对模型厂商而言，能否被 Auto 路由选中将直接影响真实调用量。 [来源](https://openrouter.ai)

**⚡ Claude Code 自动模式默认开启：不再需要逐条批准操作** — Anthropic 将 Claude Code 的自动模式设为默认选项，用户无需再批准每一个操作，官方同步解释了其安全运行原理：通过工具设计、权限边界与上下文策略判断某个操作是否可以安全执行。**为什么重要**：编码智能体从「人机共驾」走向「自动驾驶」——默认信任 + 事后可审计，是智能体真正进入生产环境的必经一步，也标志着 AI 编程从「辅助工具」到「自主执行者」的转折。**影响**：自动模式的默认化将显著提升编码效率，但权限失控的风险管理（哪些操作可自动执行、如何审计）将成为企业采用的关键议题。 [来源](https://www.anthropic.com)

**🖥️ OpenChamber 开源：跨桌面、浏览器、手机与 VS Code 的智能体开发环境** — OpenChamber 发布，一个基于代理的开发环境：支持会话目标、多模型并行运行与融合、变更走查、从 issue 到 PR 的完整流程与定时任务，基于 OpenCode SDK 构建，完全开源且免费，代码与会话内容保存在本地，远程访问可经 UI 密码与端到端加密的 Private Relay 保护。**为什么重要**：智能体开发的「IDE 化」竞争正在升温——把 Agent 工作流变成可视化、可审计、可并行的标准环境，是智能体从个人脚本走向团队协作的关键基础设施。**影响**：开源免费的定位将快速积累开发者社区，与 Cursor、Claude Code 形成差异化竞争，多模型并行与本地优先的设计也为企业私有化部署留出空间。 [来源](https://aihot.virxact.com/daily/2026-08-11)

**📊 Google Ads 与 Analytics 上线新 AI 功能：广告效果可和同类商家匿名对比** — Google 为 Google Ads 和 Google Analytics 推出新的 AI 与智能体体验：Analytics 首页新增 AI Overviews 智能摘要，Ads 首页新增 AI 洞察卡片，Ask Advisor 新增基准对比功能，可将广告效果与同类商家匿名平均值比较，功能基于 Gemini 构建，面向英文账户开放 beta 测试。**为什么重要**：广告是 Google 的利润核心，把 Gemini 塞进广告主每天打开的第一个页面，等于把 AI 能力直接转化为商业化效率——「AI 帮你发现生意问题」正在成为广告平台的新卖点。**影响**：中小广告主的投放决策将从「看报表猜」变成「AI 直接告诉你哪里不对」，广告优化师的工作重心将上移到策略层。 [来源](https://aihot.virxact.com/daily/2026-08-11)

### 📄 论文与安全

**🔢 未发布版 Claude 突破黎曼猜想相关问题：zeta 函数零点下界从 41.6% 提升至 67.2%** — Anthropic 员工让 Claude 尝试攻克黎曼猜想，虽未成功，但一个未发布的研究版 Claude 在相关问题取得突破：将满足黎曼猜想的 zeta 函数零点比例下界从 41.6% 提升至 67.2%，Anthropic 为此发布了配套技术文档。**为什么重要**：黎曼猜想是数学界最著名的未解难题之一，AI 虽未证明它，却在人类长期未动的「下界」上取得了实质性推进——这是 AI 数学研究从「验证人类思路」走向「产出人类没想到的新结果」的标志。**影响**：AI for Math 的叙事将从「辅助证明」升级为「原创发现」；但未发布研究版的成果如何复现、如何验证，也再次提醒社区需要建立可验证的 AI 数学研究标准。 [来源](https://www-cdn.anthropic.com/564f962e60643842f5fcb4a17c9dbc8f608f1c37.pdf)

**📞 tl;dv 逾 18.1 万段 AI 会议录音被公开暴露：可实时闯入他人通话** — AI 会议记录平台 tl;dv 的 Firestore 数据库因缺乏租户隔离，任何已认证用户可查询全部 18.1 万段会议记录，涉及 84,312 名用户、35,003 个域名，含 23 国政府及多所高校会议；约 1,000 场录制中的会议暴露了可加入的会议 ID，研究者借此闯入马来西亚教育部及美国某大学创业团队的实时通话。该漏洞自 2026 年 1 月报告后 6 个月仍未修复，另有超 1,000 段会议内容处于公开状态。**为什么重要**：AI 会议工具已成为企业敏感信息的「自来水管道」——录音、转录、摘要全部上云，一旦隔离失效就是大规模数据泄露；这次涉及政府与高校，性质尤其严重。**影响**：AI SaaS 的多租户安全将受到更严格审视，企业采购 AI 会议工具时会把「数据隔离审计」列为硬性条件；也再次暴露「报告漏洞 6 个月不修」的行业通病。 [来源](https://aihot.virxact.com/daily/2026-08-11)

**🖱️ a16z 数据：电脑操作智能体一年从 42% 飙到 85%，已超人类测试者** — a16z 数据显示，计算机操作智能体在 OSWorld-Verified 基准上的最佳成绩已从一年前的 42% 升至 85%，超过人类测试者约 72% 的水平，Claude Fable 5 以 85% 领先。**为什么重要**：这是「智能体真的会用电脑吗」的量化答案——一年时间近乎翻倍并反超人类，意味着「看屏幕、点鼠标」的通用电脑操作已从实验室玩具变成可信赖的自动化能力。**影响**：企业级 RPA、客服、运营等「人机界面工作」将被重新评估自动化空间，智能体操作电脑的可靠性拐点可能比预期更早到来。 [来源](https://a16z.com)
