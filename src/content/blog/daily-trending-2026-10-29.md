今天榜单的画风和前几天不太一样：AI Agent 的基础设施还在，但"让 Agent 说人话、别写出塑料味设计"这类**品味层**工具继续霸榜；社区这边则罕见地同时拿到了 V2EX 与 Linux.do 的数据，一个在聊医疗决策该信谁，一个在发公益 API 站。

## 🚀 GitHub 热门项目

- **pbakaus/impeccable**（Rust，92,822★，今日 +1,472）——给编码 Agent 的"设计词汇表"，用 polish、bolder 推进、用 critique、audit 复核，目标是在 AI 产物上线前拦掉"AI 塑料味"。榜内总星最高的一席。
- **HKUDS/DeepTutor**（Python，48,109★，今日 +2,371）——港大数据智能实验室的终身个性化辅导系统，今日新增第一，也是榜内唯一教育类项目。
- **Nutlope/hallmark**（CSS，40,799★，今日 +2,110）——反 AI 塑料味的设计技能包，面向 Claude Code、Cursor、Codex，和 impeccable 正好凑成"定标准 + 管落地"一对。
- **makecindy/cindy**（TypeScript，8,141★，今日 +728）——开箱即用的开源 AI Agent，"想到，就能做到"。
- **togg53192-cmd/jailbreaks**（7,199★，今日 +1,477）——一份越狱提示词合集，纯仓库型项目，今日新增却排到第四。
- **JetBrains/thinkrail**（TypeScript，5,130★，今日 +1,068）——JetBrains 官方轻量 vibe coding IDE，会按你的工作方式自我定制。
- **macro-inc/macro**（Rust，5,452★，今日 +117）——把邮件、聊天、文档、任务、Agent、通话和 CRM 用共享 AI 记忆 @ 到一起的统一工作区。
- **nightly-labs/openbot**（TypeScript，3,297★，今日 +1,054）——local-first 桌面工作区，Codex / Claude / Grok 各占一席，带任务队列、文件共享、浏览器控制和 Agent 间协作。

**读榜结论**：今日前八里，三席是"审美与可信度"工具（impeccable、hallmark 及其设计语言），两席是本地/开箱即用的 Agent 宿主（cindy、openbot），一席是大厂官方 IDE。能力增量已不是卖点，**"AI 写出来的东西能不能看、敢不敢用"才是**。
