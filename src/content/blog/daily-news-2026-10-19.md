> 今天的主线是「能力的定价权在换手」。模型侧，DeepSeek 的 Flash 版本用大约十分之一的成本拿下 Code Arena WebDev 开源第一，说明「便宜」和「最强」不再是两条互斥的曲线；产业侧，Anthropic 一边把 5% 股份（约 480 亿美元）注入公共利益基金、一边把员工级权限开放给外部评估机构 METR，同时承认自家技术部门初级岗位占比从 21% 掉到 14%——治理、透明度和就业影响被同一家公司同时摆上台面。规则侧，德国两家法院接连认定 Google 要为 AI Overview 的错误内容负责，「AI 只是转述」这个免责借口开始失效。国内则是另一种节奏：端侧模型、教育公益额度、计算机使用智能体栈，都是把能力往下压、往人群里铺的动作。能力、成本、责任，今天这三条线第一次同时指向同一个问题：谁来为 AI 说的话买单。

## 🇨🇳 国内动态

**DeepSeek-V4.1-Flash-20261017 登顶 Code Arena WebDev 开源榜首，成本约为对手十分之一** — Arena 公布的最新榜单里，DeepSeek-V4.1-Flash-20261017（Max 档）成为 Code Arena: WebDev 的第一名开源模型，超过 Kimi K3 (Max)，且成本低约 10 倍。这条的分量不在名次，而在「性价比斜率」：同一档能力下把单位成本压掉一个数量级，意味着下游应用的商业模型可以整个重算。WebDev 这类前端生成任务的特点是「可验证、可迭代、失败成本低」，正好是成本敏感型工作流的典型场景——当一次生成的边际成本降到几分钱，产品设计就会从「省着用」转向「多试几次再挑」。（来源：[Arena](https://x.com/arena/status/2111894091168682086)）

**腾讯 WorkBuddy 教育公益版上线：全国教师每月 2000 积分，连发 12 个月** — 腾讯 SSV 宣布 WorkBuddy 教育公益版正式上线，全国教师不限地区、不限学段，每人每月可领 2000 积分并连续领取 12 个月。产品侧联合北京大学、北京师范大学等高校，把教学设计、课件设计、家校沟通等环节拆成 100 多位「教育专家」（陆续上线），另配创意教学、剧本课堂、课件制作、动画演示、素材加工 5 个工具。这类动作的意义常被低估：AI 渗透率真正的瓶颈不是模型能力，而是「谁有资格免费用、用在哪一步」。把额度直接打到教师个人账户上，绕过了学校采购流程这块最难啃的骨头，也让「教育场景的 AI 使用数据」第一次有了规模化来源。风险在于补贴退出后的留存——12 个月之后如果积分停发，使用率会掉到多少，才是这套模式真正的成绩单。（来源：[IT之家](https://www.ithome.com/1/014/752.htm)）

**面壁智能 MiniCPM-V 4.7 升至 Hugging Face 趋势榜第二，35B-A3B 能在手机 3GB 内存跑** — OpenBMB 宣布 MiniCPM-V 4.7 升至 Hugging Face Trending 第二名。关键参数是端侧可行性：35B-A3B 的 MoE 版本可在 iOS 与 Android 上以约 3GB 内存流畅运行，1B 版本在 OCR、数学和视频理解上表现较强，模型与代码已在 Hugging Face 和 GitHub 开放。这条和昨天的「128G 统一内存笔记本」构成一组对照：一条路线把大模型塞进更贵的硬件，另一条路线把模型压到能进现有手机。后者的商业想象力更大——手机是唯一已经人人持有的 AI 硬件，端侧多模态一旦可用，隐私敏感场景（相册、证件、聊天记录）就不再需要把数据送出去。（来源：[X @OpenBMB](https://x.com/OpenBMB/status/2112024254841782712)）

**阿里通义 MAI-UI 团队开源 OpenGCUA：一整套计算机使用智能体栈** — 通义 MAI-UI 团队开源了通用计算机使用智能体（Computer-Use Agent）的完整技术栈 OpenGCUA，包含 harness、跨设备 SDK、原生 macOS 应用、评测轨迹和参考 agent 实现。这个组合值得注意的地方是「评测轨迹」也被一并放出——过去这类项目通常只开源能跑的部分，把评测集留作护城河；而 CUA 领域最缺的恰恰是可复现的轨迹数据，因为失败样本比成功样本更有信息量。对开发者来说，这意味着不用从零搭环境就能直接对着同一套标准做对比；对整个赛道来说，评测口径的统一会加速淘汰「demo 好看、真机拉胯」的方案。（来源：[X @shao__meng](https://x.com/shao__meng/status/2111999471588679916)、[GitHub](https://github.com/Tongyi-MAI/OpenGCUA)）

**「国内过半算力在造爽剧」引争议，豆包回应字节仅约 10% 用于视频生成** — 争议起点是中文在线在投资者关系活动记录表中披露的数据：国内 AI Token 消耗 55% 用于短剧和视频生成，24% 用于电商广告，真正用于研发的仅 15%。豆包公关负责人刘星回应称该算力数据不靠谱，字节总算力中只有约 10% 用于视频生成模型的训练和推理。双方口径不同（一个是 Token 消耗、一个是算力占比），但争论本身暴露了一个真问题：如果前沿算力真的主要流向内容消费而非能力研发，那么「AI 提升生产率」的叙事就需要重新校准。对做投资判断的人来说，这类结构数据比任何单点跑分都更有价值——它描述的是钱实际流向了哪里。（来源：[IT之家](https://www.ithome.com/1/014/729.htm)）

**重阳节前，京东 JoyInside 把 AI 设备带进养老院：支持河南话、能记住每位老人的喜好** — 京东 JoyInside 将搭载其能力的消毒机、AI 小夜灯、AI 营养秤和 AI 机器狗带进许昌福瑞园养老院，老人用口语即可开灯、启动消毒或让机器狗表演。技术细节里最实的两个是：支持中文、英文和河南话识别，以及具备长期记忆、能记住每位老人的偏好。银发场景的 AI 落地一直卡在「交互门槛」而非「功能数量」——老人不会打字、不愿学新界面，语音是唯一现实的入口；而方言识别和个体记忆这两件事，恰好是把「语音助手」变成「护理助手」的分水岭。这类项目目前仍是企业公益性质的样本，但它验证的交互路径，比任何养老机器人的概念视频都更接近可复制。（来源：[京东 JoyInside](https://mp.weixin.qq.com/s?__biz=MzU0MjU0MDMzMw%3D%3D&mid=2247487528&idx=1&sn=a185dac109d95a86bd885a8a9651611d)）

**中信证券：DeepSeek Harness 是生态关键一环，开源与工程优势可转成用户基础** — 中信证券研报认为，DeepSeek Harness 有望成为 DeepSeek 从「模型供给」走向「平台生态」的关键一环。该框架由深度求索于 2026 年 8 月开源，MIT 许可证、TypeScript 编写、主打「一切皆插件」。券商研报通常滞后于技术，但这次判断的逻辑是成立的：模型层的护城河正在被开源稀释，真正能留住开发者的是 harness 这类「工作流层」——它决定了工具调用、上下文管理、插件生态，一旦形成使用习惯，迁移成本远高于换一个模型 API。换句话说，DeepSeek 卖的可能不再是模型，而是「怎么用模型」的标准答案。（来源：[IT之家](https://www.ithome.com/1/014/646.htm)）

## 🌍 国际动态

**Anthropic 将 5% 股份注入公共利益基金：按 9650 亿美元估值约合 480 亿美元** — Anthropic 设立 Anthropic Public Benefit Fund，承诺投入 5% 股份，按 9650 亿美元估值计算约合 480 亿美元；董事会还可在公司价值超过某条未公开基线后，每上涨 50% 追加 2%。这是 AI 公司治理结构的一次实质性试验：把「公共利益」从一份使命宣言变成一份可估值、可追索的股权。值得追问的有两点——基金的实际决策权归谁，以及这笔钱在什么条件下可以被调用。如果只是把股份放在一个由公司自己主导的基金里，「480 亿美元」更接近公关数字；如果外部受托人拥有独立投票权，那才是真正的结构性让步。（来源：[X @rohanpaul_ai](https://x.com/rohanpaul_ai/status/2112047682466570502)）

**Anthropic 向 METR 开放「类员工」访问权限，六名评估人员已入驻** — Anthropic 宣布向非营利评估机构 METR 开放接近员工级别的访问权限：已有六名 METR 工作人员入驻，获配公司硬件、办公场地，以及与内部风险评估团队大致等同的内部工具和系统权限。这是外部红队评估的一次规格升级——过去第三方评估拿到的多是 API 和文档，模型内部行为、训练细节、部署配置基本不可见。让外部人坐在内部系统里，等于把「自我评估」的一部分不可让渡地主权交出去。风险也明显：访问权限越大，保密与利益冲突管理越难，METR 的报告一旦与 Anthropic 的商业叙事冲突，谁来决定发不发、怎么发，是这套安排真正的考验。（来源：[IT之家](https://www.ithome.com/1/014/651.htm)）

**Anthropic 内部研究：技术部门初级岗位占比从 21% 降至 14%，Agent 工时是员工的六倍** — 今日 AI HOT 日报的头条。Anthropic 发布基于内部数据的技术报告：技术部门初级员工占比从 2025 年初的 21% 降到 14%，新招初级占比从 27% 降到 9%，空缺初级职位降到 6%，而非技术部门基本稳定。同期交互式 AI agent 的工时已达员工的 6 倍。把这几个数字连起来看，结论比「AI 抢工作」更精确：被替代的不是「人」，而是「以训练新人为目的的低价值任务」——写测试、改文档、修简单 bug，这些原本是初级工程师的学习路径。企业省下了培养成本，代价是整个行业失去了养成通道。三五年后「有经验的工程师」从哪里来，这份报告没有回答。（来源：[The Decoder](https://the-decoder.com/anthropic-has-nearly-stopped-hiring-junior-staff-because-ai-agents-now-work-six-times-as-many-hours/)、[Anthropic Research](https://www.anthropic.com/research/employment-at-anthropic)）

**德国两家法院先后认定 Google 须为 AI Overview 的错误内容负责** — 慕尼黑地区法院 I 在五月底裁定：Google 的 AI 搜索摘要属于公司自己的「陈述」，而非对第三方内容的中立转述，因此须为错误内容担责。Google 公开宣布上诉后，实际以和解结案，未获上级法院裁决；另一家德国法院随后作出类似认定。这条的法律意义在于切断了「我只是搬运」的免责逻辑：传统搜索可以援引「信息中介」地位，而生成式摘要把多源信息重新组织成一句新话，那句话在法律上就是平台自己的言论。对企业的影响是直接的——AI 概览的幻觉不再只是产品体验问题，而是可诉的侵权风险，这会推动「引用可溯源」从加分项变成合规项。（来源：[The Decoder](https://the-decoder.com/two-german-courts-now-hold-google-liable-for-what-its-ai-overviews-say/)）

**亚马逊、达美航空、摩根大通开始封禁 AI 智能体** — 一条来自 X 的观察：亚马逊、达美航空和摩根大通正在封禁 AI 智能体访问。评论者用乔布斯最初拒绝第三方 iPhone 应用作类比——后来苹果推出 App Store，生态反而大成。这个类比有说服力但也有盲区：App Store 的开放是「有身份、可追责」的开放，而当前大部分智能体是无身份、无担保、无法定责的自动化流量。企业封禁的真实原因通常不是「反对 AI」，而是「无法审计、无法追偿」。所以更可能的终局不是长期封锁，而是出现一套智能体身份与授权基础设施——谁来签发「这个 agent 代表谁、能做什么、出了事谁赔」，这才是被卡住的环节。（来源：[X @Yuchenj_UW](https://x.com/Yuchenj_UW/status/2112030814905180441)）

**NVIDIA 将 Run:ai 平台以 Apache 2.0 完整开源** — NVIDIA 把收购来的 Run:ai 平台整体开源，源码以 Apache 2.0 发布在 GitHub，平台团队可以检视、fork 和自托管，无需付费订阅。放在更大的图景里，这是典型的「开源上层、卖底层」：Kubernetes 层的 GPU 编排被免费化，价值向硬件和互联转移。对中小团队的直接好处是省掉一笔调度软件订阅费；长期看，GPU 调度标准的开放会降低多云迁移摩擦，也就降低了被单一供应商锁定的风险——这对买方是好事，对卖方的议价能力则是微妙的一击。（来源：[MarkTechPost](https://www.marktechpost.com/2026/10/18/nvidia-runai-open-source-gpu-orchestration-kubernetes/)）

## 📄 论文与研究

**Cohere Labs：多智能体编码团队能超过单 agent，但成本高 3 到 7 倍** — 论文《Scaling Inference-Time Compute with Teams of Coding Agents》研究多智能体编码团队的算力分配，结论是团队确实优于单 agent，但成本要高出 3 到 7 倍；更细的发现是角色分配很关键——宜由强模型领队，便宜模型负责规划类工作。这基本上给「堆 agent」的热潮泼了一盆冷水：多智能体的收益不是线性的，编排开销和重复劳动会吃掉大部分增益。真正可用的结论只有一条——把钱花在「领队」上，而不是无差别地增加 agent 数量。（来源：[X @rohanpaul_ai](https://x.com/rohanpaul_ai/status/2112048784457060471)）

**MIT 研究：AI 篡改的图片能植入从未发生的记忆，且当事人更自信** — 据《华盛顿邮报》报道，MIT 媒体实验室 Pattie Maes 团队让 200 名受试者观看照片，看过 AI 篡改版本的人产生错误记忆的概率大幅上升，且对虚假记忆更加自信。这是比「深度伪造」更深一层的问题：伪造图像不只是欺骗观看者当下的判断，还能改写其后的记忆基础。法律上的后果很直接——目击证词、影像证据的可信度都需要重新评估；产品上的后果同样具体——任何以「回忆」为核心的功能（相册回顾、日记生成、家庭影像修复）都在无意识地进行记忆编辑。这条研究值得被当作设计约束，而不是新闻谈资。（来源：[IT之家](https://www.ithome.com/1/014/768.htm)）

**Open-Science 追问递归自我改进：基础模型冻结，DGM 靠改周边软件把解决率从 20% 提到 50%** — 有人用开源 AI 科研工作台 Open-Science 开了个 RSI（递归自我改进）项目，追踪技术路线与经济账。已复现的数据点：DGM 在 200 个任务的 SWE-bench 子集上、基础模型完全冻结的情况下，经过 80 轮自我修改把任务解决率从约 20% 提升到 50%——所有改进都发生在模型周围的软件里。这解释了一个常被混淆的问题：现在所谓「自我改进」，改的是脚手架而非权重。它的天花板由脚手架的可改进空间决定，但短期内这是最便宜的能力增长路径，也最容易失控——因为改的是代码，而代码可以无限次迭代。（来源：[X @dongxi_nlp](https://x.com/dongxi_nlp/status/2112021227082481843)）

## 🛠️ 产品更新

**ChatGPT 支持回溯编辑提示词并续聊，桌面端可改历史消息** — OpenAI 上线了两个长期被要求的功能：可以回溯对话中的某条提示词、编辑后从那里继续，原理是丢弃被编辑提示词之后的所有消息与工具调用，避免模型上下文混淆；桌面应用也支持直接编辑历史消息。看起来是小改动，实际改的是交互范式——过去对话是单向追加的日志，现在变成可分支的树。对使用者来说，这意味着不必为了修正一句表述而重开一段对话；对产品来说，「分歧点重跑」是 agent 工作流里最常被需要、也最容易被忽略的一环。（来源：[X @reach_vb](https://x.com/reach_vb/status/2112002870929473551)、[X @thsottiaux](https://x.com/thsottiaux/status/2111990254408434095)）

**Grok Bot 开放 X 上的 @bot 调用，任务可以直接从时间线发起** — X 与 Grok 账号已连接的用户，现在可以在 X 上直接 @bot 派任务，例如「把这条推文存到我的 Notion 阅读列表」；官方强调 bot 只响应用户明确给出的实际任务。这是把 agent 的入口嵌进社交信息流：不需要打开另一个应用，看到内容的同时就能触发动作。与 ChatGPT 的 Chrome 标签页控制对照着看，两种路线正在分化——一个把 AI 塞进浏览器，一个把 AI 塞进社交图谱。谁的上下文更值钱，取决于用户在哪里产生意图。（来源：[X @larsencc](https://x.com/larsencc/status/2112022330667106408)）
