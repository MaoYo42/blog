榜单今天彻底回到了「Agent 的装修队」模式：记忆层、游戏工作室、Grokk 替代品、离线听写各占一席，而 V2EX 那边一半人在感叹行情冷，一半人在算网易云会员能领几天。十一月第一周的福利也在换挡——Epic 本周的真免费只剩最后一款，下一档要等到周五。

## 🚀 GitHub 热门项目

按今日新增 star 排序。榜单页已改为客户端渲染总星数，此处只取「stars today」，不混用总星；已剔除 sponsors 赞助位卡片。

- **pingdotgg/t3code**（TypeScript，今日 +3,094）— 榜单介绍文案为空，但已是连续第四期在榜，热度反而一路走高，本周新增第一。
- **thedotmack/claude-mem**（TypeScript，+1,526）— 给各类 Agent 做跨会话持久上下文，把 Agent 干过的每一件事都记下来，明确支持 Claude Code／Codex／Gemini／Copilot 等宿主。
- **Donchitos/Claude-Code-Game-Studios**（Shell，+967）— 把 Claude Code 改造成一间完整的游戏开发工作室：49 个 AI agent 加 72 条工作流技能，属于「用配置文件堆出一个团队」的路子。
- **milind-soni/OpenMausBot**（TypeScript，+922）— 开源版 Grok Bot 替代品，亮点是给 bot 配了一台可操作的虚拟机。
- **lightpanda-io/browser**（Zig，+825）— 专为 AI 与自动化设计的无头浏览器，用 Zig 重写走轻量低内存路线，与 Puppeteer 系正面竞争。
- **shiyu-coder/Kronos**（Python，+630）— 「金融市场语言」的基础模型，把 K 线当作文本序列来建模，是榜内少见而非 Agent 类的项目。
- **cjpais/Handy**（Rust，+339）— 完全离线运行的语音转文字应用，免费、开源、可扩展，隐私敏感场景的实用选项。
- **public-apis/public-apis**（Python，+324）— 老牌免费 API 合集，常年挂在榜上，做副业或练手时仍是最好用的索引起点。

一句话读榜：前五席里三席在解决「Agent 记不住、管不住、不像个团队」的问题，能力增量继续让位于工程化与可控性，这个判断本周依旧成立。
