### 🚀 GitHub 热门项目

今日 Trending 主线仍是 **Agent 生态**，但重心继续从"通用框架"下沉到**具体行业与具体工种**——CAD、建筑、金融、图示、终端工作流都在被 Agent 重写：

- **ayghri/i-have-adhd**（Python，34.8k★）— 让 coding agent "别把答案埋起来"：输出压缩、重点前置的 ADHD 友好技能包，连续两日霸榜。
- **cathrynlavery/diagram-design**（HTML，36.7k★）— 38 种编辑级图示模板，纯 HTML + SVG 自包含输出，作者明确反对 Mermaid 糊图，适配 Claude Code / Codex / Pi。
- **TauricResearch/TradingAgents**（Python，104.0k★）— 多智能体 LLM 金融交易框架，把"研究员—交易员—风控"角色拆成可对话的 Agent 流水线，常驻热榜。
- **rohitg00/ai-engineering-from-scratch**（Python，53.7k★）— AI 工程从零到落地的完整学习路径，配代码与项目交付，适合研0自学补基础。
- **pascalorg/editor**（TypeScript，23.0k★）— 开源 3D 建筑编辑器，自带本地 CLI 与 MCP 工具，可直接被 AI Agent 驱动建模。
- **earthtojake/text-to-cad**（Python，15.1k★）— 面向 CAD / CAE / CAM 的 Agent 技能库，自然语言到工程制图的尝试。
- **liquidslr/system-design-notes**（18.0k★）— 《System Design Interview》读书笔记，系统设计面试的速查底稿。
- **Tencent/teamai-cli**（TypeScript，3.0k★）— 腾讯开源团队级 AI 原生命令行工具，主打"让每个团队 AI Native"，国产大厂 Agent 工具链的又一入场者。
