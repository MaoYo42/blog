## 🚀 GitHub 热门项目

今天 Trending 榜单的主线很清楚：**agent 的工作方式还在被重新设计**——有人让它更像资深工程师（少写代码），有人给它配安全审计技能，有人把它变成地面部队，也有人把代码库整体变成可查的知识图谱。

1. **anomalyco/opencode** — TypeScript · 218,985★（今日 +1,240）
   开源编码 agent，仍是这条赛道的事实参照物。

2. **DietrichGebert/ponytail** — JavaScript · 169,792★（今日 +1,208）
   "让你的 AI agent 像屋里最懒的资深工程师那样思考。最好的代码是你从没写过的代码。" 一个反向优化 agent 输出量的思路。

3. **msitarzewski/agency-agents** — Shell · 162,395★（今日 +562）
   一整套"AI 代理机构"：前端、社区运营、创意、现实核查各司其职，每个 agent 一个角色设定。

4. **Comfy-Org/ComfyUI** — Python · 140,819★（今日 +1,206）
   最强大的模块化扩散模型 GUI / API / 后端，节点式界面，本地推理引擎里速度最快的一档。

5. **Graphify-Labs/graphify** — Python · 130,317★（今日 +802）
   把任意代码库连同文档、SQL schema、配置、PDF 转成可查询的知识图谱，作为 Claude Code / Cursor / Codex / Gemini CLI 的 `/graphify` 技能使用。

6. **stablyai/orca** — TypeScript · 99,816★（今日 +1,565）
   管理一整支 agent 舰队的工作台：用你自己的订阅跑任意编码 agent，桌面端、移动端、远程运行时都能接。

7. **ruvnet/ruflo** — TypeScript · 77,875★（今日 +684）
   自称"最早的 agent harness"：多智能体 swarm 编排、自主工作流、自适应记忆与自学习。

8. **MadsLorentzen/ai-job-search** — Python · 60,746★（今日 +3,861，今日涨幅第一）
   跑在你自己机器上的求职流水线，基于 Claude Code：筛岗位、改简历、写 cover letter、准备面试，一条链走完。

9. **cloudflare/security-audit-skill** — JavaScript · 34,339★（今日 +1,712）
   Cloudflare 出的编码 agent 技能：多阶段安全审计，结论必须可独立复核、机器可读。

> 观察：榜单里"给 agent 装技能"和"给 agent 减输出"同时上榜，说明大家已经不满足于能跑，开始关心跑得对不对、跑得贵不贵。
